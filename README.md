# Tracelo（工作时间线）

Obsidian 单设备任务进展插件。左侧持续展示当前待办，右侧显示每日时间线或单任务完整历史。

仓库：https://github.com/skybcyang/Tracelo

当前版本 **0.9.0**：搜索显示命中片段和日期，可直接定位原记录；修复中文输入法选词，窄窗口提供“任务／历史”切换。进展与完成节点更醒目，完整历史保留。展示模式已移除，卡片、弹窗与时间轴沿用统一蓝灰视觉语言。

本版保留完整图标选择器、统一卡片布局、顶栏显示设置；设置中可选择“顶部对齐（默认）”或每列独立排列的“瀑布流”。切换布局或缩放不刷新右侧时间线。详情默认完整展示，创建任务时即可填写，兼容旧存档。长内容通过单张卡片展开查看。详见[当前卡片规则](docs/design/content-adaptive-cards.md)。

从 [Releases](https://github.com/skybcyang/Tracelo/releases/latest) 下载 Obsidian 插件、macOS Universal 应用包（Apple Silicon / Intel）和 Windows x64 快捷程序（自带 .NET，另需 WebView2 Runtime）。桌面工具无需启动 Obsidian 即可创建任务，详见[桌面工具安装与使用](desktop/README.md)。应用尚无开发者签名／公证；自动验证与实际输入法、多屏、焦点恢复等实机验证分别记录，不混作已通过。验证范围见[发布验收](docs/validation/2026-09-28-release-090.md)，数据兼容约定见[任务上下文协议](docs/design/task-context-protocol.md)。

## 功能

- 连续时间轴直接显示进展、生命周期和逐条属性变更；翻阅旧记录时不跳走，新进展可主动定位
- 紧凑创建表单固定底部操作栏，可选内容按需展开；取消保留会话草稿，⌘Enter / Ctrl+Enter 创建
- macOS 菜单栏和 Windows 托盘快捷创建；与插件共用完整新建表单，支持独立标题／详情、分组、四象限、待办、截止日期与初始进展，失败保留草稿
- 分组与四象限视图，共享同一批任务并支持跨区域拖动
- 卡片内追加进展、按任务持久化草稿、最近进展自动置顶
- 可选图文详情：创建时可填写，默认完整展示；支持 Markdown、图片粘贴／拖入／上传、独立大图预览；后续详情修改单独留痕，不伪造进展
- 卡片收起时标题最多两行、最新进展三行、前三项未完成待办各两行；更多内容在原卡片展开，已完成待办可折叠查看
- 60%～120% 看板缩放，保留偏好及草稿；单张卡片展开查看完整内容，通过菜单修改图标和标题
- 任务与分组使用 Noto Emoji 彩色图标，3,729 个可选图标随包离线提供；支持常用中文词／英文名称搜索、分批浏览、继承分组与隐藏。旧 Lucide 标识仅在显示时映射为彩色图标，保留原存档与历史；工具栏操作按钮仍使用 Obsidian 的线性图标
- 可选的单层待办清单与截止日期；截止安排显示在每日时间线，变更保留历史
- 卡片以进度环和分数展示待办，今天截止与逾期使用有文字说明的状态色；分组／四象限内可点击虚线卡片新建任务
- 分组视图隐藏重复组名，四象限视图隐藏重复优先级；已结束卡片仍保留完整上下文
- 卡片空白点击展开，右键与三点菜单共用；菜单提供详情、进展、待办及任务文件夹操作，分组／象限使用二级菜单
- 完成、异常关闭、重开、改名及属性变更的完整追加式历史
- 统一已结束区，以及任务名称和进展内容全文搜索
- 自然语言 Markdown 文件名：`2026-09-26 完成支付模块.md`，内部保留固定任务 ID
- 完整导入／导出：卡片、分组、草稿、排序与材料；预览导入结果，已有任务按 ID 跳过
- 自动生成 `agent.md`，禁止 agent 直接修改任务存档
- 最近 7 个备份日期轮换、升级／迁移快照、异常文件与中断操作恢复

正式任务和历史默认保存在 `工作记录/任务/`。草稿、排序和界面偏好保存在插件数据中；旧 JSON 任务不会迁移，首次切换前会先备份。

任务文件与按需创建的材料目录使用“创建日期 + 任务名称”，同日重名追加 `（2）` 等序号。日期取任务原始创建事件的本地日期，改名不改日期；已有 UUID Markdown 和材料目录首次加载时会先备份，再自动迁移。待办、截止日期与历史不会拆成额外文件。

点击工具栏“导入与导出”，或使用同名设置入口／命令。导出为单个 `.tracelo.json` 包，包含已有材料（包括二进制文件和空目录），上限 100 MB。导入先校验和预览；同 ID 跳过并保留本地内容，不同 ID 同名任务自动加序号，同名分组复用。本版不提供覆盖已有任务或合并同一任务历史的模式。0.6.0 补充了统一任务目录中的附件备份与恢复，跨设备迁移仍使用完整导出包。

## 开发

要求 Node.js ≥ 22.12。

```sh
npm install
npm test          # vitest 单元/契约测试
npm run build     # 类型检查 + esbuild 产出 main.js
npm run test:layout  # 布局、滚动与真实卡片交互检查（需要 playwright 浏览器）
npm run check     # 依次执行以上全部
```

卡片默认使用原生 CSS Grid：同宽、顶部对齐、各自按内容定高，下一行位于上一行最高卡片下方。设置中的“瀑布流”让各列独立向下排列，展开时不跨列移动；改变列数时才重新分列，键盘阅读沿各列向下。100% 时最小卡宽 260px、间距 12px、内边距 18px、底部 20px，取消旧版 148px 整格取整。收起时仅限制摘要，展开后完整显示内容。看板缩放同步作用于文字、卡片尺寸和间距，工具栏与时间线不缩放。

卡片交互测试直接加载插件渲染代码，并模拟 Obsidian 的默认控件样式和图标 API，覆盖展开／收起、可选字段、清单编辑、日期、草稿及深浅色响应式布局。使用已安装的 Chrome 时运行 `PLAYWRIGHT_CHANNEL=chrome npm run check`。

0.5.0 验证记录（2026-09-27）：46 项单元测试、27 组布局测试、71 项实际渲染交互检查、独立滚动检查及类型检查／构建通过。覆盖待办进度、截止状态、历史完整性、深浅色文字对比度及两行进展的两格展开回归；本目录 Obsidian 1.13.7 已复核新设计的展开、收起与四象限效果。详见[紧凑设计实现规范](docs/design/compact-ui.md)。

## 本地安装

在目标仓库的 `.obsidian/plugins/` 下创建 `work-timeline` 文件夹，将以下文件放入其中：

```text
main.js
manifest.json
styles.css
```

重新加载 Obsidian 后，在“第三方插件”中启用“Tracelo”。点击左侧历史图标，或从命令面板运行“打开工作时间线”。

从旧版本升级到 `0.3.0` 时，插件在首次加载旧任务后生成升级快照；任务 Markdown 继续使用兼容的 v1 协议。无需给既有任务补写待办或截止日期。

`0.4.0` 增加任务文件夹、自然语言命名与完整导入导出。升级时保留现有任务与插件数据，首次加载旧 UUID 存档会先备份再迁移名称。请通过插件操作任务改名；手动改名／编辑正式任务文件仍不受支持。任务或材料目录改名后，外部手工维护的路径链接需要相应更新。完整升级说明见 [0.4.0 更新说明](docs/releases/0.4.0.md)。

`0.5.0` 保持存档格式和导入导出协议兼容。替换三个插件文件并重新加载即可升级，保留 `data.json`、任务、材料与备份目录。

`0.6.0` 继续兼容旧 v1 存档。建议先完整导出，再替换三个插件文件并重载，保留 `data.json` 与数据目录。已有独立材料目录会先备份后迁入任务同名目录，内部图片引用保持有效；外部手工维护的路径链接需自行更新。含备注／图标的新存档不保证被旧插件理解，回退应使用升级前完整备份。详见 [0.6.0 更新说明](docs/releases/0.6.0.md)。

`0.7.0` 请配套使用同版插件和快捷程序。新写入的 Markdown 正文使用「详情」，内部仍为兼容的 `notes` 字段；新插件接受旧「备注」正文，旧插件不保证读取新版正文。升级仍只替换三个插件文件，不替换 `data.json`，也不删除任务或附件。可按 Release 的 `SHA256SUMS.txt` 核对下载文件。

`0.8.0` 继续使用 v1 存档协议；替换三个插件文件并重载，桌面应用同步升级。旧快捷程序的一段式草稿自动迁移为独立名称与详情；新建任务可选全部属性，默认仍为未分组、不重要、不紧急。Windows 需安装 WebView2 Evergreen Runtime，缺失时应用会提供安装入口。详见 [0.8.0 更新说明](docs/releases/0.8.0.md)。
