# 顶栏精简、分组溢出与菜单主题

本轮沿用现有四主题，保留工作区此前的等高卡片、展示模式和动效改动。只更新源码与隔离验证，未安装或发布，未修改正式任务数据。

## 行为

- 移除顶栏右上角独立的“快捷记录”闪电按钮；新建弹窗的“记录进展”切换、卡片入口与桌面快捷工具继续保留。
- 分组按原排序显示能放下的前几项，后续项进入“更多分组”；窗口变宽时恢复，全部能放下时隐藏下拉入口。
- 选中折叠分组时入口显示该分组名。切换视图保留筛选，新建继续带入当前分组；下拉支持方向键、Home/End、Esc、Tab 离开及点击外部关闭。
- 长分组名在顶栏省略，在下拉内换行。菜单位置限制在当前插件面板内，避免选中长名称后首次展开越界。
- 卡片右键与更多按钮继续共用 Obsidian 菜单行为，使用 DOM 菜单以套用插件主题。主菜单与分组／象限子菜单同步颜色、字体、图标、圆角和分隔线；不改其他 Obsidian 菜单。

- `node tests/entry-audit.browser.mjs`：11 项卡片操作入口、子菜单及失败反馈检查通过。
- `node tests/collection-interface.browser.mjs`：主题、草稿、快捷记录原有流程通过；测试入口改为新建弹窗内切换。
- `npm run test:layout`：完整布局套件通过，包含卡片交互、内容、可读性、详情、时间线、新建与搜索导航回归。
- `npm run build`、`git diff --check` 通过。
