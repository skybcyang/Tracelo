# 2026-10-16 移除任务 Emoji

用户明确最新设计不再适用 Emoji，可删除。本轮移除生产界面的任务／分组 Emoji 及图标设置入口，不改写正式任务。保留品牌标记、操作和象限的 Lucide 图标；旧存档的 `icon` 字段、属性事件及旧命令继续兼容。未提交、推送或发布。

## 实现与画面

- 展示台、封面流、全屏总览和展开看板不再渲染任务 Emoji；分组标题不再显示 Emoji，象限语义图标保留。
- 删除任务图标菜单、分组图标按钮、选择器、图标渲染器及 Noto npm 依赖；插件和桌面 bundle 不再捆绑整套 Noto 图库。
- 桌面快捷进展的当前任务与任务选择器同步移除图标，收紧网格空列；切换箭头和选中勾保留。
- 界面浏览不改写旧数据；隔离测试另验证带 `noto:laptop` 的任务改名后仍保留图标字段及原历史。现有领域／存档兼容测试保留。

当前生产组件使用隔离内存样本，已亲自查看浅深色截图：[浅色](../../test-results/no-emoji/light.png)、[深色](../../test-results/no-emoji/dark.png)。标题和分组文字直接承担身份，无空图标槽；沿用现有玻璃设计。本轮为局部减法，自检，未进行独立视觉评审。删除的界面文字包括“更换图标…”及“设置分组图标”等入口；没有改写用户标题或正文。历史原型与旧截图保留原貌。
