# 0.7.0 集成与发布验收

## 依赖与合并

- 先保留已有未提交的图标、顶栏、详情和布局偏好变更，并通过 80 项原有单元测试与构建。
- 隔离分支 `codex/timeline-ui` 负责连续时间轴，`codex/create-ui` 负责紧凑创建表单及界面审视，`codex/windows-capture` 负责 Windows 快捷应用。
- 主线 `codex/release-0.7.0` 整合三分支，负责 macOS Universal 应用、发布流程、兼容性与文档。

## 验证

- `DOTNET_PATH=/tmp/tracelo-dotnet/dotnet PLAYWRIGHT_CHANNEL=chrome npm run check`：81 项单元／协议测试、类型检查、生产构建、256 项浏览器检查及独立滚动通过。Windows 协议测试使用临时本地 .NET SDK；未修改系统 SDK 设置。
- `swift run --package-path desktop CaptureCoreTests`：5 项核心检查，包括多行协议、原子不覆盖、重试、目录边界、输入策略及面板尺寸。
- `bash desktop/package-macos.sh`：arm64 与 x86_64 Release 编译、Universal 合并、ad-hoc 签名验证及打包应用启动通过。
- Windows 核心 9 项检查、三组 C#／TypeScript 严格逐字节兼容样例、自包含 win-x64 发布构建通过。
- [首轮远端 CI](https://github.com/skybcyang/Tracelo/actions/runs/36397416830)：Linux 插件、macOS 原生、Windows 原生全部成功；Windows `.exe` 实际启动的 16 项检查通过，深浅色输入／设置截图逐张复核。
- `git diff --check`：通过。界面证据及各界面边界见[审视记录](2026-09-28-ui-review.md)。

集成回归先发现“新增任务时在底部未跟随”的真实行为遗漏，新增失败用例后修复；原瀑布流回归没有被削弱。macOS 从命令行二进制转为 `.app` 后暴露偏好域同名启动错误，修复后将应用包启动加入发布验证。

## 数据与边界

真实宿主替换插件前完整备份插件目录与任务目录到仓库外临时目录；没有提交 `.obsidian`、真实任务、个人偏好或导出包。升级后逐文件比较原任务目录不变。新版插件列表已显示 0.7.0，但系统随后锁屏，未完成最终原生设置和时间轴目视复核。

真实中文输入法候选、多屏／全屏定位、焦点恢复、真实触屏及第三方主题仍需实机检查。Windows 消息模拟与 CI 窗口截图不能替代这些组合；macOS 系统界面连接超时，没有声称已通过原生交互。应用暂未开发者签名或公证。

## 发布门禁

Release 工作流在标签版本与包版本一致、插件全量检查、macOS 应用包检查和 Windows 应用启动全部通过后，统一创建 Release。资产包含插件三文件和 ZIP、macOS Universal ZIP、Windows x64 ZIP 与 SHA-256 校验文件；任一平台失败均不发布不完整 Release。
