# 卡片布局设置验收

日期：2026-09-28。当前工作区新增，尚未发布或加载到正在运行的 Obsidian。

## 行为

- 插件设置提供“卡片布局”：顶部对齐（默认）、瀑布流。旧数据及未知配置回退到顶部对齐。
- 瀑布流保持等宽，按既有任务顺序依次分配到各列；每列自然排版。展开、收起与图片加载不改变所属列，窗口或缩放改变列数时重新分列。
- 分组、四象限、已结束区均使用所选布局。切换布局保留当前进展输入、草稿、任务顺序，以及右侧时间线节点、内容和阅读位置。
- 偏好保存失败时恢复原值和下拉选择。导入空仓库恢复导出布局，已有任务的仓库保留本地布局。
- 采用普通列容器保留自然高度；只监听容器尺寸以响应列数变化，重绘或关闭视图时断开监听。瀑布流的 DOM／键盘顺序沿列向下。
