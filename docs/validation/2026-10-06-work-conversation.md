日期：2026-10-06。最新授权：保留右侧上方原有元素，仅用工作对话替换下方混合时间轴。实现依据见 [设计说明](../design/work-conversation.md)。

## 实现范围

- 上方日期切换、周历、当日截止保持原位置；下方默认对话，通过“活动记录”或卡片“查看历史”显式进入旧历史视图，可返回对话。展开卡片不切走对话。
- 多轮讨论、会话切换、输入草稿、引用卡片和待确认提议持久保存。@选择关联稳定任务 ID，只有明确引用的任务上下文进入模型请求。
- 支持新建、追加进展、名称／详情／截止日／分组／重要紧急与待办修改。模型返回受限提议；允许人工编辑，确认才调用现有存档服务。未引用对象、过期任务、非法字段及危险操作被拒绝。
- 使用稳定操作身份，失败保留草稿与编辑，重试不重复追加；取消或切换后忽略迟到响应。对话输入保持稳定 DOM，Enter 换行，组合键提交，组合输入期间不提交。
- 新建复用共享表单，模型设置复用现有直接输入 API Key 的设置。未来步骤整理为待办，不伪装成已发生进展。
- 首版不含批量修改、任务状态变更、自动任务检索和流式逐字回复；完整回复生成中可停止。
