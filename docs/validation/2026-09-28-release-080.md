## 预检发现与修复

- Windows 真实 WebView2 在 `NavigateToString` 导航事件中报告内嵌 `data:` URI，旧拦截器只允许 `about:blank`，造成空白表单。修复为只额外允许与本次内嵌 HTML 字节完全对应的地址；外部导航、网络、下载和权限仍被禁用。同时修复退出时重复释放窗口导致的异常。[Windows 原生复验](https://github.com/skybcyang/Tracelo/actions/runs/36420395885/job/108921441131)通过，日志验证完整草稿、热键及冲突、分组变化、任务保存和失败保留。
- 新 Chromium headless 环境不再保证存在 `window.chrome`；补齐浏览器测试夹具的 WebView2 桥接初始化，在相同浏览器上确认失败转为通过。
- 创建弹窗的延迟聚焦可能抢走已经选中的详情字段，使后续输入落入标题。增加确定性回归，先复现失败，再限制初始化聚焦仅发生在用户尚未选中弹窗控件时；6 项创建回归通过。
