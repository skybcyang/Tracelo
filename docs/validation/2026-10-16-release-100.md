## 已接入

展示台、模块悬停预览／拖入、行列增减与比例调整、按任务保存布局、撤销与恢复默认、背景切换及自定义图片、完整圆角牌组与边缘淡出。保留原位进展、草稿和编辑节点；分组／四象限及展开看板继续使用现有任务。布局和背景保存于插件偏好，未改正式任务 Markdown。

## 材质偏差与修正

生产截图中，背景摄影已经加载，但左侧展示台与牌组呈近乎实心的浅灰色。检查实际计算样式发现 `.wt-task-column` 继承旧看板的 `background: var(--wt-bg)`，实际为 `rgb(231, 233, 235)`；因此子卡片的透明与背景模糊只能采到灰底。默认银灰背景也漏接了 Mockup 的折光层。

修正从这一处遮挡入手：工作台滚动载体改为透明，保留展开看板原有背景；补回银灰背景折光与渐变，恢复空间玻璃外壳、柔和磨砂正文的分层。照片背景按明暗外观调整曝光与覆盖，避免暗色照片使控件失读。背景装饰限制在容器内，避免超宽折光影响总览的滚动尺寸。未通过整体降低界面透明度实现效果。

新增遮挡回归先失败后通过（`.local/glass-material-red.log`、`.local/glass-material-green.log`）。对照依据为 [既有 Mockup](../design/modular-stage/index.html) 的 `materials.css`、`modular.css`、`backgrounds.css` 与 `deck.css`；未另换设计方向。

## 恢复发布后的收尾

版本契约预检通过，GitHub API 与 Git 传输已核对，远端尚无 1.0.0 标签。收尾复现“鼠标拖动比例后保存失败，画面未恢复”的缺陷：存储状态已回退，但临时设置的网格比例仍留在 DOM。新增真实鼠标回归先失败，再修复保存失败分支的比例恢复；相关证据见 `.local/release-100/resize-failure-red.log`、`resize-failure-green.log`。修正后重新执行完整检查，后续结果逐项追加，不以早前检查替代。

设计原型及文档引用的关键截图入仓；未引用的完整逐帧采样留在本机原目录和安全快照，避免将重复的大体积帧组混入发布。生产材质证据另保存于本页所列 `test-results`。
