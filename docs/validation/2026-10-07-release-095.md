# 0.9.5 发布验证

范围：当前开发版的工作对话、一句话录入、可编辑任务协议及 32 项已批准 UI 修改。使用独立发布工作树，保留原开发目录的未提交状态。版本、升级文档与已知问题统一为 0.9.5。

发布采用候选分支三平台预检通过后再打标签，正式附件由 Release 工作流重新验证并发布。本记录在候选阶段不预先宣称远端成功；运行 SHA、工作流、附件校验与安装结果在发布后补充。

## 本地发布准备

- 环境：macOS，Node.js 26.7.0，Playwright Chromium，Swift 与 .NET 8 SDK。
- 版本契约：6 项通过；插件、macOS、Windows 版本均为 `0.9.5`，最低 Obsidian 版本仍为 `1.8.0`。
- 领域与跨语言单元测试：20 个文件、134 项通过；生产类型检查与构建通过。
- Swift CaptureCore：10 项通过；C# CaptureCore：18 项通过。
- 更新测试以适配批准的界面：待办编辑／删除通过三点菜单进入；历史事件按 ID 验证完整保留，仅省略重复正文；展示模式关闭图标保留可访问名称；快捷取消等待关闭动画并检查草稿保留。
- 将工作对话浏览器回归加入 `npm run check`，正式候选与标签 CI 均执行。
- 本地完整检查已分段执行通过：最初 `npm run check` 在旧 UI 测试预期处中断；修正后从失败脚本继续至末尾，覆盖布局、主题、历史、搜索、图文创建、快捷记录、展示模式、动效、一句话录入和工作对话，未跳过余下检查。后续 CI 对最终提交重新运行完整命令。
- 本轮 24 份变更 Markdown 的本地相对链接无缺失，`git diff --check` 通过。
- `npm audit --omit=dev`：0 项漏洞。完整依赖审计仍有 3 项开发依赖告警（Obsidian SDK／moment 及 source-map-js），本轮未混入依赖升级，不能表述为全依赖无告警。

## 验证边界

本轮不调用真实模型、不读取真实密钥，不在正式任务上测试写入。真实中文候选、多屏、系统快捷键冲突、跨应用焦点和 Windows 完整手工交互仍未全量验收。UI 变更的图证和尺度对比见 [批准项验收](2026-10-07-approved-ui.md)。

已知的快捷一句话按钮样式、短窗口日历末行裁切保留为后续设计问题，见 [发布说明](../releases/0.9.5.md)。
