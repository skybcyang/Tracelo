# 看板可读性调整验收

日期：2026-09-29。基于 0.9.0 的工作区改动，已安装到本地 WorkAssistant 库并重载，尚未发布 release。

## 观察与调整

改动前在 WorkAssistant 测试库的实际 Obsidian 看板检查到：详情图片排在最新进展之前，完整大图使进展和截止日期落到卡片下部；底部只有日期时间，需悬停才能区分创建时间和进展时间。此次按视觉层级、就近识别和状态可见性调整：

- 标题从 15px/650 调整到 16px/700；最新进展从 12px 弱化色调整到 13px 主文字色。
- 截止日期移至标题下方，并明确“截止／今天截止／已逾期”；最新进展移至完整详情之前，保持文字和图片不裁切。
- 当天实际进展显示“最新进展 · 今天”。底部保留原来的靠右时间位置，增加“进展／创建”和当天提示；修改详情不改变实际进展日期。
- 选中卡片显示“正在查看历史”，与右侧历史标题区的蓝色边线对应；用户主动收起时同步取消任务选择并回到原先日期的全部任务时间线，进展草稿保留。
- 回归中复现长卡片收起后标题上沿 52.36px、可见区域上沿 64px，旧逻辑仅检查标题是否完全离屏。改为检查标题上沿，必要时将卡片顶部滚回可见区域。

保留现有分组、四象限、排序、两种卡片布局和缩放；收起态的标题两行、进展三行、待办摘要与展开阅读行为保持原样。没有增加 AI、筛选器或新的存储字段。既有 `docs/design/quick-progress/` 原型未改动。
