# Tracelo 0.6.0

任务卡片改为等宽、自然高度、顶部对齐，减少内容结束后的空白；新增图文备注、卡片图标、缩放与展示模式，并统一任务和材料目录。

## 变化

- 卡片中性细边框、轻阴影、12px 圆角与 18～20px 内边距，适配深浅主题。取消 148px 整格高度，按行保留阅读与拖动顺序。
- 收起态标题最多两行、最新进展三行、前三项未完成待办各两行；其余待办显示数量，已完成项可折叠查看。完整阅读仍在原卡片展开，完成分数只显示一处。
- 可选 Markdown 图文备注，支持图片粘贴／拖入／上传、大图预览、草稿与独立属性历史；备注不生成普通进展。修复真实 Obsidian 首次上传因文件夹事件重绘而丢失图片引用的问题。
- 可选任务图标及轻量标题编辑入口，任务时间线选中与卡片编辑展开状态分离。
- 60%～120% 看板缩放（每步 5%）和展示模式，保留偏好及草稿；展示模式完整显示信息，点击单卡再进入编辑。
- 按需将任务 MD 和材料归入同名任务目录；旧材料目录先备份再迁移。附件纳入每日备份和完整导出，导入失败及文件竞争时恢复原数据。
- 插件即时接入外部新增的合法 v1 任务文件并去重；附带实验性 macOS Swift 菜单栏工具源码，第一行为标题、后续内容写入备注。

## 安装与升级

从本 Release 下载 `main.js`、`manifest.json`、`styles.css`，放入 vault 的 `.obsidian/plugins/work-timeline/`，重新加载 Obsidian。最低 Obsidian 1.8.0。

升级前建议先完整导出。保留 `data.json`、任务、材料和备份目录；已有 v1 存档兼容读取，首次加载进行版本快照和必要的目录迁移。任务内部图片引用保留，外部手工维护的路径链接需随目录变化更新。含新增字段的存档不保证被旧插件理解，回退请使用升级前完整备份。

## 验证与限制

本地通过 76 项单元／协议／磁盘测试、27 组布局、85 项交互、78 项自然高度检查，以及独立滚动、类型检查和生产构建；当前目录 Obsidian 1.13.7 复核核心流程、图文备注、备份导出恢复及新卡片交互。详细证据见[验收记录](https://github.com/skybcyang/Tracelo/blob/0.6.0/docs/validation/2026-09-28-integration.md)。

macOS 工具只提供实验性源码，无签名／公证安装包：Release 构建、4 项核心测试、跨语言存档和插件接入已验证，但原生窗口自动化连接超时，实际输入法、快捷键冲突、多屏／焦点恢复尚待验收。真实触屏／移动端、系统截图快捷键、从外部应用拖入，以及 Windows 文件夹前台激活仍待实机复核；浏览器合成事件不替代这些验证。详见[桌面工具说明](https://github.com/skybcyang/Tracelo/blob/0.6.0/desktop/README.md)及 [task 状态](https://github.com/skybcyang/Tracelo/blob/0.6.0/task.md)。
