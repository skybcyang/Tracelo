# Tracelo 0.9.1

统一看板与快捷记录的设计语言，加入截止日历、图文快捷进展与四套主题，并简化新建任务入口。

## 本次更新

- 四套主题：矿物绿、石墨紫、冰川蓝、暖白朱砂，支持深浅色与跟随宿主；同仓库桌面快捷工具同步主题。
- 分组导航直接显示在顶部，组内横向铺卡，支持稳定瀑布流和紧凑卡片；每日时间线新增周日期条。
- 移除分组和四象限内的虚线新建占位框，保留顶部“新建任务”和区块标题旁的加号；空分组仍可接收拖入任务。
- 新增截止日历，可按月查看任务与所选日列表，支持跳转和状态更新。
- 桌面新增“记录进展”，默认 Control+Option+P／Ctrl+Alt+P。搜索选择任务后追加图文进展或修改待办，任务选择器可展开与收起。
- 插件和桌面共用图文创建表单，支持图片粘贴、多选、拖入、预览、移除与撤销；草稿按仓库及任务目录隔离，失败时保留内容。
- 内置 3,729 个 Noto 彩色图标，支持离线搜索、分页、继承与隐藏。
- 修复分组管理、图片预览、象限选中／悬停与已结束任务操作受到宿主明暗设置干扰的问题，统一按钮圆角、日历控件和拖拽反馈。
- README 精简为产品介绍，开发与验收资料移至独立文档。

## 下载与升级

| 文件 | 用途 |
| --- | --- |
| `Tracelo-0.9.1-obsidian.zip` | Obsidian 插件：main.js、manifest.json、styles.css |
| `Tracelo-Capture-0.9.1-macos-universal.zip` | macOS 13+，Apple Silicon 与 Intel |
| `Tracelo-Capture-0.9.1-windows-x64.zip` | Windows 10/11 x64，自带 .NET 8 |
| `SHA256SUMS.txt` | 下载文件 SHA-256 校验值 |

插件要求 Obsidian 1.8.0 或更新版本。替换 `.obsidian/plugins/work-timeline/` 中的三个插件文件并重载，保留 `data.json`、任务、材料和备份目录；建议先备份。既有 v1 任务存档继续兼容，无需重建。

请同时升级插件和桌面工具。快捷新建可以在 Obsidian 关闭时直接保存含图片任务；快捷进展及既有任务修改会先进入持久命令队列，插件未运行时显示“已暂存”，插件确认写入后才清空进展草稿。旧插件不会消费新命令队列。

Windows 需要 WebView2 Evergreen Runtime；macOS 使用系统 WebKit。macOS 包仅作 ad-hoc 签名，尚未开发者签名／公证；Windows 程序尚未代码签名。
