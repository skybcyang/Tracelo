# Tracelo 0.3.0

2026-09-26 重建发布，包含可选待办／截止日期功能与真实 Obsidian 中的卡牌 UI 修复。

## 功能与修复

- 任务可不设置待办和截止日期，也可只设置其中一项或同时使用两项；不显示空占位。
- 待办支持新增、勾选、编辑、删除和撤销；截止安排显示在每日时间线，变更保留历史。
- 对齐交互设计稿的卡牌展开与折叠布局，修复宿主默认按钮导致的灰底、居中、文字裁切和控件文字丢失。
- 保留 148px 基础卡高与 12px 间距，长内容按最少整数格扩展，不强制四格。
- 已有清单显示完成数、行分隔和常驻新增输入框；展开不再自动跳到进展输入框，草稿继续保留。
- 修复时间线链接灰底与“当日截止”区域被历史记录挤压。

## 安装与更新

下载本次 Release 的 `main.js`、`manifest.json`、`styles.css`，覆盖目标仓库的 `.obsidian/plugins/work-timeline/` 对应文件，然后重新加载 Obsidian。

此次沿用 **0.3.0** 版本号并替换原发布附件。已安装此前 0.3.0 的用户需要重新下载覆盖，不能仅依靠版本号检测更新。任务存档与插件数据无需删除。

最低 Obsidian 版本：1.8.0。任务 Markdown 保持 v1 兼容格式。

## 验证

- 31 项单元／契约测试。
- 27 组卡牌布局场景，以及独立滚动检查。
- 24 项带 Obsidian 宿主样式的真实渲染检查，覆盖可选属性、清单、日期、草稿、响应式和时间线布局。
- 本地 Obsidian 1.13.7 中检查展开／折叠及四种属性组合的真实用例。
