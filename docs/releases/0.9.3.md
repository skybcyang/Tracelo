# Tracelo 0.9.3

让看板更整齐、长内容更容易阅读，并统一导航、卡片菜单与快捷保存反馈。

## 本次更新

- 默认紧凑模式使用等高卡片：标题单行，标签与截止日期横排，最新进展固定两行；展开后完整阅读详情与待办。
- 新增“展示模式”：完整展示当前筛选内的全部卡片，同时只编辑一张。结束编辑或提交成功后仍保留完整阅读，模式切换保留草稿、中文输入和时间线阅读位置。
- 加入卡片展开／收起、轻聚焦、待办进度和新增时间线记录动效，兼容系统减少动态效果；保留稳定瀑布流顺序与阅读锚点。
- 顶栏移除独立“快捷记录”图标；新建弹窗内的进展切换、卡片入口和桌面快捷键继续可用。
- 分组按排序展示能放下的前几项，其余收入“更多分组”；支持当前选项提示、长名称、窗口缩放与键盘操作。
- 卡片右键、三点菜单及分组／象限子菜单统一四套主题的颜色、字体、图标、圆角与间距。
- 插件、macOS 与 Windows 共享保存反馈：明确区分提交中、待同步、成功和失败；确认写入后才清稿和退出，防止旧回调关闭新会话或重复提交。
- 修正需求与协议文档中关于展示模式、时间线方向、分组导航、任务文件夹、附件备份及草稿保留范围的过时说明。

## 下载与升级

| 文件 | 用途 |
| --- | --- |
| `Tracelo-0.9.3-obsidian.zip` | Obsidian 插件：main.js、manifest.json、styles.css |
| `Tracelo-Capture-0.9.3-macos-universal.zip` | macOS 13+，Apple Silicon 与 Intel |
| `Tracelo-Capture-0.9.3-windows-x64.zip` | Windows 10/11 x64，自带 .NET 8 |
| `SHA256SUMS.txt` | 三个平台 ZIP 和独立插件文件的 SHA-256 校验值 |

插件要求 Obsidian 1.8.0 或更新版本。备份后替换 `.obsidian/plugins/work-timeline/` 中的三个插件文件并重载，保留 `data.json`、任务、附件和备份目录。现有 v1 存档继续兼容，升级不会清空任务或重建历史。

旧“紧凑任务卡片”偏好迁入展示模式：此前关闭紧凑模式的用户保持完整阅读，此前开启紧凑或未设置的用户使用等高卡片；已有明确展示模式偏好优先保留。设置中不再提供重复开关。

请同时升级插件和桌面快捷工具。新建可以在 Obsidian 关闭时直接保存；快捷进展及既有任务修改会先持久暂存，插件确认写入后才清空进展草稿。插件新建草稿仅保留于本次 vault 会话，任务进展／详情草稿与桌面草稿按各自协议持久保存。

Windows 需要 WebView2 Evergreen Runtime；macOS 使用系统 WebKit。macOS 包为 ad-hoc 签名，未作开发者签名／公证；Windows 程序未作代码签名。
