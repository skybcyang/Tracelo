# Tracelo 0.9.7

修复存档异常、文件移动和历史引用造成的阻塞，改善短窗口截止日历。

## 本次更新

- 分组档案损坏时保留 `_groups.md` 原文和最近有效备份，暂停正式写入及导入／导出；修正文件后自动恢复。保存前检查外部变化，避免用过期分组覆盖正在编辑的文件。
- 任务文件移出管理目录或改成非任务文件时及时移除卡片，保留草稿和移出的文件；符合存档协议的任务移回后恢复识别与保存。
- 删除历史引用任务后，移除当前引用即可继续原会话；历史消息保留引用身份，模型只获得仍可用的任务，不能修改已移除的任务。
- 六周月份按窗口高度调整日期格；更短或更窄窗口可滚动访问日期、任务列表和关闭按钮。
- 每日备份直接复制任务及分组原字节，避免启动备份改写手工编辑格式；升级快照保留异常分组原文。
- 整合当前开发目录与已发布源码，统一插件、macOS 和 Windows 的 0.9.7 版本及发布产物。

## 下载与升级

- Obsidian：`Tracelo-0.9.7-obsidian.zip`，含 `main.js`、`manifest.json`、`styles.css`。
- macOS 13+：`Tracelo-Capture-0.9.7-macos-universal.zip`，支持 Apple Silicon / Intel。
- Windows 10/11 x64：`Tracelo-Capture-0.9.7-windows-x64.zip`，自包含 .NET，需 WebView2 Evergreen Runtime。

保留 `data.json`、任务目录、附件和桌面工具草稿；替换插件三件套并重载 Obsidian，桌面工具配套升级。旧任务协议继续兼容，首次迁移先保留原格式备份。本次不改变任务身份、追加历史规则或卡片密度。

## 验证边界

异常路径、短窗口与主题矩阵加入自动回归；三平台候选和标签工作流分别验证插件与原生构建。完整证据见仓库 `docs/validation/2026-10-08-release-097.md`。

中文候选窗、真实多屏／全屏焦点、听写麦克风及 Windows 人工 GUI 矩阵仍需设备验收。macOS 为 ad-hoc 签名，未公证；Windows 未代码签名。
