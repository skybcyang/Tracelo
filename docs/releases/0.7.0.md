# Tracelo 0.7.0

本版完成时间轴与创建体验更新，并首次同时提供 macOS 与 Windows 快捷创建应用。

## 更新内容

- 时间轴沿连续主轴直接呈现全部事件，取消属性历史折叠；进展、生命周期与属性变更保持原顺序。新增前后日导航，翻阅旧记录时保持位置，通过「有新进展」主动定位最新内容。
- 创建弹窗采用紧凑属性选择器和按需展开的待办、截止日期、初始进展。底部操作栏保持可见；⌘Enter / Ctrl+Enter 创建，输入法组合期间不提交。取消保留会话草稿，显式清空或成功创建才移除。
- 纳入完整图标选择器、顶部对齐／瀑布流偏好、顶栏显示设置和完整图文详情；显示设置不打断右侧时间轴阅读。
- macOS 快捷浮窗使用清晰的首行标题层级、独立错误提示、可点击创建按钮及保存位置入口，随内容和屏幕可用高度调整。
- 新增 Windows 托盘快捷工具：可配置全局快捷键、浮动输入、草稿、目录校验和原子不覆盖保存。与 macOS 一致：首行为标题，其余行写入详情，只生成创建事件。

## 下载

| 产物 | 用途 |
| --- | --- |
| `main.js`、`manifest.json`、`styles.css` | Obsidian 插件；保留单文件形式供更新工具使用 |
| `Tracelo-0.7.0-obsidian.zip` | 上述三个插件文件的安装压缩包 |
| `Tracelo-Capture-0.7.0-macos-universal.zip` | macOS 13+，Intel / Apple Silicon 通用 `.app` |
| `Tracelo-Capture-0.7.0-windows-x64.zip` | Windows 10/11 x64，自带 .NET 运行时的 `.exe` |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验值 |

插件文件放入 vault 的 `.obsidian/plugins/work-timeline/`，重载后启用。桌面工具解压后运行，通过菜单栏／托盘设置 vault 与实际任务目录。默认全局快捷键为 Control+Option+Space（macOS）或 Ctrl+Alt+Space（Windows）。

## 升级与兼容

升级前建议完整导出。替换三个插件文件，保留 `data.json`、任务、附件与备份。仍使用 v1 存档；新插件兼容旧「备注」正文，新写入使用「详情」。快捷程序须与 0.7.0 或更新的插件配套使用；回退旧插件应恢复升级前完整备份。

macOS 应用仅使用 ad-hoc 签名，未作开发者签名或公证；Windows 未作代码签名。系统可能显示未验证发布者提示。应用不自动注册开机启动，不启动网络服务。

## 验证边界

发布流程要求插件全量检查、macOS 核心／跨语言协议／双架构构建／打包启动检查，以及 Windows 核心／原生构建／应用启动检查全部成功后才发布资产。实际中文输入法候选词、多屏／全屏定位、原应用焦点恢复、真实触屏与第三方主题仍需实机复核；不以模拟事件或 CI 截图代替这些结论。

界面覆盖与证据见[界面审视](../validation/2026-09-28-ui-review.md)，桌面工具详见[安装与开发](../../desktop/README.md)。
