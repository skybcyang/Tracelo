# Tracelo 0.8.0

Obsidian、macOS 和 Windows 现在使用同一份完整创建表单。名称和详情独立填写，可选择实际任务分组、重要／紧急四象限，以及待办、截止日期和初始进展；四象限保留四项直接可见的 2×2 布局。

## 本次更新

- 快捷窗口与插件共用字段、样式、校验和任务构建逻辑。⌘Enter / Ctrl+Enter 创建，Esc 保留草稿；旧快捷程序的文本草稿自动迁移，失败重试不重复创建。分组变化会提示重新选择。
- 卡片时间始终靠右，属性在左侧换行；详情文字与图片直接显示在标题下，移除重复的“详情／编辑详情”行。
- 改名、更换图标、详情和文件夹操作集中到右键／更多菜单，取消重复图标和“切换卡牌保留草稿”提示。自动保存草稿行为不变。
- 菜单补齐添加／编辑详情、记录进展与添加待办；分组、象限的具体选项及选中标记移到二级菜单。
- 修复首条待办的输入法组合保护、部分操作保存失败时缺少提示，以及任务已创建但偏好保存失败时容易重复提交的问题。

## 下载与升级

| 文件 | 用途 |
| --- | --- |
| `Tracelo-0.8.0-obsidian.zip` | 插件三文件：main.js、manifest.json、styles.css |
| `Tracelo-Capture-0.8.0-macos-universal.zip` | macOS 13+，Apple Silicon 与 Intel |
| `Tracelo-Capture-0.8.0-windows-x64.zip` | Windows 10/11 x64，自带 .NET 8 |
| `SHA256SUMS.txt` | 下载文件 SHA-256 校验值 |

插件仍要求 Obsidian 1.8.0 或更新版本。建议先完整导出备份，然后替换 `.obsidian/plugins/work-timeline/` 中的三个插件文件并重载；保留 `data.json`、任务、材料和备份目录。快捷程序退出后替换应用，并与同版插件配套使用；保存位置须与插件的 vault 和任务目录一致。

Windows 需要 [WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。缺失时应用提供安装入口，不会自动下载。macOS 使用系统 WebKit，无需额外运行时。macOS 包仅作 ad-hoc 签名，尚未开发者签名／公证；Windows 程序尚未代码签名。

存档继续使用兼容的 v1 协议，详情内部字段仍为 `notes`，无需重建现有任务。新插件接受旧“备注”正文；不建议使用 0.6.0 或更早插件读取新工具创建的存档。回退时应恢复升级前备份。
