# Tracelo 1.0.3

本版改善长任务的阅读和短窗口的操作体验，并进一步统一 Obsidian 插件与 macOS／Windows 快捷工具的界面。

- 展示台中的进展、待办、详情和目录各自滚动，长正文不再撑高所有模块；标题、记录进展、添加待办和编辑入口保持可见。窄窗口自然上下排列，空间不足时保留外层滚动以便访问全部内容与操作。
- 勾选待办、调整布局和同任务刷新时保留模块阅读位置及编辑草稿；目录尚在加载时进入详情编辑，也能在列表返回后恢复阅读位置。新进展从新正文顶部显示，切换任务不会串用阅读位置。
- 统一新建／直接进展表单的标签、阅读面板、输入和按钮，以及弹窗、图片预览的主题外观。插件和桌面快捷窗口共用样式，五套主题与独立深浅色继续可用。
- 调整短窗口工作对话的间距和消息区高度，让发送按钮更容易到达；保留日期、日历和截止信息。修正深色引用文字、总览工作助手按钮及快捷页标签的排版。

## 下载与升级

从本页下载 `Tracelo-1.0.3-obsidian.zip`、`Tracelo-Capture-1.0.3-macos-universal.zip` 或 `Tracelo-Capture-1.0.3-windows-x64.zip`，使用 `SHA256SUMS.txt` 核验。

插件替换 `main.js`、`styles.css`、`manifest.json` 后重载；保留 `data.json`、任务目录及草稿。快捷程序退出后替换并重新打开，vault／任务目录应与插件一致。本版沿用原有任务存档协议和已保存的布局配置。

macOS 包为 Universal、ad-hoc 签名，未做开发者公证；Windows x64 包自带 .NET，需 WebView2。安装与配置见[桌面说明](../../desktop/README.md)。

本轮已完成创建、进展、历史、对话、草稿恢复及失败重试等流程回归，并针对长正文、短窗口和异步目录增加检查。具体证据见[流程与界面验收](../validation/2026-10-24-flow-polish.md)及[模块滚动验收](../validation/2026-10-24-stage-scroll.md)；三平台构建、正式发布、附件核验和安装状态见[1.0.3 发布验收](../validation/2026-10-24-release-103.md)。自动原生窗口检查不等同于真实中文候选窗、听写、多屏／全屏及完整实体快捷键验收。
