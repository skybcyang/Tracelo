# 2026-09-29 开发更新（未发布）

> 历史记录：本批改动已纳入 [0.9.1 发布说明](0.9.1.md)。下文保留版本升级前的开发与安装状态。

当前本地 `main` 已整合四组功能、四主题界面及后续导航／图标／任务切换修改。发布基线仍是标签 0.9.0（`f561840`）；本地版本字段保持 0.9.0，不代表开发构建等同于发布附件。最终验证与分支记录见[一致性与合并记录](../validation/2026-09-29-consistency-integration.md)。

- 顶栏“截止日历”打开月历弹窗，展示任务摘要和所选日完整列表，支持跨月、今天、状态更新与窄窗口。
- 桌面新增“记录进展”入口，默认 Control+Option+P／Ctrl+Alt+P，可独立配置；插件也有快捷入口。先搜索选择任务，再填写图文进展和修改待办。选择框点一次展开、再点一次收起，保留任务与草稿。
- 插件与桌面共用创建／进展表单；当前快捷窗口约 554px，底部操作固定可见。详情编辑区采用“插入图片／取消／保存详情”操作栏。
- 插件和桌面新建详情支持图片粘贴、多选、拖入、预览、移除与撤销。PNG、JPEG、WebP、GIF、BMP 每张最多 10 MB，草稿图片总计最多 40 MB。
- 默认矿物绿，可切换石墨紫、冰川蓝、暖白朱砂及深浅色；插件向同仓库桌面工具同步主题。
- 辅助界面统一跟随插件主题：修复分组管理、图片预览、象限选中／悬停及已结束任务操作受宿主外观干扰的问题；统一表单和操作按钮圆角、日历控件与拖拽高亮。见[界面审查与修正](../validation/2026-09-29-interface-consistency.md)。
- 双层导航直接显示分组；恢复分组上下排列、组内横向铺卡及稳定瀑布流。缩放不影响工具栏和时间线。
- 移除分组和四象限内的虚线新建占位卡，使用顶栏“新建任务”或区块标题旁的加号添加；空分组仍可接收拖入任务。
- 卡片常态展示详情摘要与全部待办，可开启紧凑模式；右侧时间线保持常驻，新增周日期条，最新记录位于顶部。
- 任务／分组内置 3,729 个 Noto 彩色图标，选择器支持离线搜索、分页、继承与隐藏，并适配四主题。
- 拖拽目标高亮保留卡片四周约 12px 留白，不改变网格布局。

快捷创建仍直接发布新任务，Obsidian 关闭时也可创建含图片任务。快捷进展及既有任务修改先写入持久命令队列；插件未运行时显示“已暂存”，插件确认正式写入后才清空进展草稿。失败保留输入，相同请求可幂等重试。草稿按仓库与任务目录隔离。

使用新增快捷修改能力需要同时升级插件和对应桌面工具；旧插件不会消费新命令队列。既有 `work-timeline-task:v1` 存档继续兼容，不改旧任务格式。两端共用源组件与样式，已安装旧版需重新构建／升级，不提供运行时热更新。

标准 Markdown 由桌面本地渲染，图片仅显示宿主读取的本地附件；Obsidian 特有嵌入和第三方 Markdown 扩展仍以插件中的呈现为准。

2026-09-30 已重新安装本仓插件与 macOS 快捷工具，包含 Noto、任务切换、一致性修正及新建占位卡移除；安装文件与构建内容逐项核验一致。备份和实机检查范围见[安装验证](../validation/2026-09-29-interface-consistency.md)。不能仅凭应用显示 0.9.0 判断源码一致；本次未推送或发布 Release。

早期功能与真实仓库验收见[四组任务记录](../validation/2026-09-29-all-tasks.md)，界面演变见[四主题差异报告](plugin-collection-vs-0.9.0.md)。Windows 实机与完整原生输入法、多屏、快捷键、焦点矩阵仍待补齐。
