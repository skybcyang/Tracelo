# 2026-09-29 开发更新（未发布）

本轮实现 `task.md` 的四组功能，未更改已发布的 0.9.0 版本号，未安装或发布本轮构建。

- 顶栏“截止日历”打开月历弹窗，展示任务摘要和所选日完整列表，支持跨月、今天、状态更新与窄窗口。
- 桌面新增“记录进展”入口，默认 Control+Option+P／Ctrl+Alt+P，可独立配置。先搜索并选择任务，再使用共享展开卡片记录进展或修改待办、属性。
- 新建表单统一为 600px 卡片样式，详情编辑区采用“插入图片／取消／保存详情”操作栏。
- 插件和桌面新建详情支持图片粘贴、多选、拖入、预览、移除与撤销。PNG、JPEG、WebP、GIF、BMP 每张最多 10 MB，草稿图片总计最多 40 MB。

快捷创建仍直接发布新任务，Obsidian 关闭时也可创建含图片任务。快捷进展及既有任务修改先写入持久命令队列；插件未运行时显示“已暂存”，插件确认正式写入后才清空进展草稿。失败保留输入，相同请求可幂等重试。草稿按仓库与任务目录隔离。

使用新增快捷修改能力需要同时升级插件和对应桌面工具；旧插件不会消费新命令队列。既有 `work-timeline-task:v1` 存档继续兼容，不改旧任务格式。两端共用源组件与样式，已安装旧版需重新构建／升级，不提供运行时热更新。

标准 Markdown 由桌面本地渲染，图片仅显示宿主读取的本地附件；Obsidian 特有嵌入和第三方 Markdown 扩展仍以插件中的呈现为准。
