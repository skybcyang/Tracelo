# Tracelo 0.4.0

2026-09-27。本版增加任务文件夹、自然语言存档名称和完整导入导出，并修复卡片点击范围与展开高度。

## 新功能

- 任务文件夹按需创建：卡片右键与右上角三点菜单共用“创建文件夹／打开文件夹”，已有目录显示快捷图标。文件夹操作仅桌面端可用，材料由系统文件管理器管理。
- 任务文件和材料目录使用“创建年月日 + 任务名称”，例如 `2026-09-26 完成支付模块.md`。同日重名追加 `（2）` 等序号，任务 ID 与历史保持不变；通过插件改名会同步更新文件及已有材料目录。
- 工具栏、设置页或命令面板打开“导入与导出”。单个 `.tracelo.json` 包包含任务、待办、截止日期、历史、分组、草稿、排序，以及材料文件和空目录。
- 导入先校验并预览，确认后写入。同 ID 的任务整张跳过、保留本地内容；新 ID 的同名任务另存并加序号。同名分组复用，失败或中断提供恢复流程。

## 交互与布局修复

- 点击卡片空白、正文或元信息即可选中并展开；已展开时点击空白保持展开，点击标题可收起。输入、按钮、文字选择和拖动不会额外触发展开。
- 保留 148px 基础卡高与 12px 间距，卡片按最少整数格增长。修复添加入口和进展输入区间距重复叠加的问题：桌面两行进展、仅截止日期的周报用例由三格 468px 回到两格 308px。
- 长进展与长待办仍完整换行；窄屏保留操作区域尺寸，深浅色和独立滚动继续支持。

## 安装与升级

下载本次 Release 的 `main.js`、`manifest.json`、`styles.css`，覆盖目标仓库的 `.obsidian/plugins/work-timeline/` 对应文件，然后重新加载 Obsidian。最低 Obsidian 版本仍为 1.8.0。

保留现有任务文件、插件 `data.json` 和备份目录。升级会生成版本快照；旧 UUID Markdown 和材料目录首次加载时先备份，再迁移为自然语言名称，创建日期、任务 ID、待办、截止日期及历史保持不变。任务 Markdown 继续兼容 v1 协议。

升级前建议备份整个仓库，以同时保留材料。插件每日轮换备份仅覆盖任务等管理数据，不包含材料；0.4.0 的完整导出包包含材料。旧版散装 JSON 数据不在本次导入支持范围内。

迁移或改名后，外部手工维护的文件路径链接需要自行更新。正式任务文件仍应通过插件管理，不支持手工改名或编辑。

## 当前边界

- 完整导出包上限 100 MB（编码后大小）；更大的材料需另行复制。
- 不提供同一任务历史的覆盖或合并，不支持任意 Markdown、ZIP 或旧版散装 JSON 导入。
- 不提供材料数量、附件列表或将文件拖到卡片自动导入；默认不创建空材料目录。

## 验证

- 46 项单元／契约测试，包括真实临时文件系统下的命名、迁移、冲突及中断恢复。
- 27 组布局测试、45 项实际插件渲染交互检查及独立滚动检查。
- 类型检查与构建通过；本地 Obsidian 1.13.7 已复核周报卡片的真实展开高度。
