# Tracelo 0.5.0

2026-09-27。本版将新的紧凑设计落实到插件，减少重复文字，用克制的语义颜色展示进度和截止状态。

## 界面与交互

- Tracelo 图标保留左上角；白底卡片配细蓝色展开边框，深浅色控件和关键文字对比度同步优化。
- 待办使用比例进度环与分数，全部完成显示绿色；未来截止日期保持中性，今天截止使用琥珀色，逾期保留浅红底与文字提示。
- 分组视图省略重复组名，四象限视图省略重复优先级；象限标题使用低饱和色，已结束卡片仍显示完整上下文。
- 分组与象限内增加虚线“新建任务”入口，带入所在区域属性，取消恢复焦点，创建后显示并展开新任务。
- 时间线在原位置折叠连续属性变更，可展开查看全部记录；进展、生命周期事件及截止安排继续完整保留。
- Windows 文件夹入口改为直接调用 Explorer，路径通过独立参数传递，失败时保留已有目录并提示。macOS／Linux 保持原打开方式。

## 保持兼容

148px 基础网格、12px 间距与按内容占最少整数格不变；长文字完整换行，展开卡片与同组等宽，窄屏仍可访问时间线。可选待办／截止日期、空白点击展开、右键菜单、草稿、任务文件夹、自然语言命名、导入导出与备份继续可用。

## 安装与升级

下载本次 Release 的 `main.js`、`manifest.json`、`styles.css`，覆盖仓库 `.obsidian/plugins/work-timeline/` 中对应文件，重新加载 Obsidian。最低版本仍为 1.8.0。

保留 `data.json`、任务文件、材料与备份目录。存档及导入导出协议不变，升级沿用版本快照；既有任务无需补填待办或日期。完整导出仍为 `.tracelo.json`，上限 100 MB，已有任务按 ID 跳过。

## 验证与边界

- 46 项单元／契约测试、27 组浏览器布局、71 项实际渲染交互检查、独立滚动、类型检查与构建通过。
- 验证深浅色、窄屏、缩放、最少整数格、进度环、截止状态、历史完整性、关键文字对比度和既有文件夹／迁移流程。
- 已在本地 Obsidian 1.13.7 复核真实展开、收起和四象限效果。
- Windows 调用已通过平台模拟测试，前台激活效果仍需 Windows 实机复核；不声称已完成实机验证。
