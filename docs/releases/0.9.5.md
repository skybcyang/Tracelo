# Tracelo 0.9.5

把任务讨论、快速录入与本地 Markdown 编辑连接起来，同时保留紧凑卡片的阅读密度。

## 本次更新

- 新增右侧工作对话：多轮讨论、@卡片引用和可编辑的修改建议；确认后才创建或修改任务。日历、截止安排、每日活动与单任务历史继续保留。
- 新建页统一“手动填写／一句话整理”，支持桌面插件、macOS 和 Windows；任务内可用一句话记录进展。支持直接输入并隐藏 API Key、连接测试、返回原文、恢复结果与草稿保护。
- 任务升级为可编辑 YAML＋Markdown：详情、待办和进展正文只保存一份，手动保存后刷新看板。双击卡片正文或使用菜单可打开任务文件；无效格式及并发冲突不自动覆盖原文件。
- 快捷记录和模型录入等待正式写入回执后再清稿；重试沿用稳定操作身份，减少重复创建和重复进展。
- 待办操作收进常显三点菜单，保留编辑、删除与撤销；增大操作点击区，主题焦点样式统一。快捷记录增加“取消”，关闭时保留草稿。
- 精简顶栏、卡片、新建、对话、日历、搜索及历史的重复说明。卡片标题、正文、两行摘要与收起高度保持原尺度；普通“收起”保留，展示模式“结束编辑”改为关闭图标。
- 改善窄屏面板切换与短窗口工作侧栏滚动，保留输入框和发送按钮的可达性。默认主题为黑白灰“素白”，其他配色继续可选。

## 下载与升级

| 文件 | 用途 |
| --- | --- |
| `Tracelo-0.9.5-obsidian.zip` | Obsidian 插件：main.js、manifest.json、styles.css |
| `Tracelo-Capture-0.9.5-macos-universal.zip` | macOS 13+，Apple Silicon 与 Intel |
| `Tracelo-Capture-0.9.5-windows-x64.zip` | Windows 10/11 x64，自带 .NET 8 |
| `SHA256SUMS.txt` | 三个平台 ZIP 与独立插件文件的 SHA-256 校验值 |

需要 Obsidian 1.8.0 或更新版本。升级前备份任务目录、附件、插件配置及已有备份；替换 `.obsidian/plugins/work-timeline/` 内三个插件文件并重载，保留 `data.json`。旧存档会先备份再迁移为可编辑格式，任务 ID、历史和附件继续保留。

**请同时升级桌面快捷工具。** 旧工具无法正确列出新版 YAML 任务。快捷创建可在 Obsidian 关闭时保存；既有任务修改和快捷进展先持久排队，由新版插件确认写入。回退旧版本前请使用升级前的完整备份，不要让旧插件直接编辑迁移后的目录。

模型功能需要自备 HTTPS Chat Completions 兼容服务。仅发送当前描述、会话及明确引用的必要任务信息，确认前不写任务；不配置模型时离线功能仍可用。Key 保存于普通本机配置，并非系统钥匙串，分享配置或备份前需移除凭证。模型结果需要人工检查，调用可能计费。

macOS 使用系统 WebKit；Windows 需要 WebView2 Evergreen Runtime。macOS 包为 ad-hoc 签名、未公证，Windows 程序未作代码签名。

## 已知边界

- 快捷记录的“一句话记录进展”按钮样式仍待统一；短窗口截止日历的末行底边可能被裁切。这两项未混入本轮已批准的 UI 修改。
- 自动与原生冒烟检查不能替代真实中文输入法、多屏、系统快捷键冲突、剪贴板和跨应用焦点的完整人工验收。
- 不包含多任务自动拆分、无需确认的批量写入、自动提醒或独立麦克风录音入口。
