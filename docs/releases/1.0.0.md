# Tracelo 1.0.0

用玻璃工作台集中恢复当前任务的上下文，自由安排进展、待办、详情与材料目录。

## 本次更新

- 展示台成为完整的玻璃卡片；正文采用柔和磨砂，分组与象限筛选使用统一样式，移除任务／分组 Emoji 和选择器。
- 左侧模块悬停预览，按住拖入右侧加入或移动；列间增加列、卡片间增加行，新列及目标列内新行默认均分，分界线支持拖动和键盘调整。
- 自定义布局按任务稳定身份保存，改名不丢失，切换任务恢复各自布局；支持撤销和恢复默认。收回模块不删除正文或草稿。
- 背景支持银灰光影、雾蓝山景、建筑光影与自定义图片；可调整明暗和柔焦。自定义图片随插件配置保存在本地，不上传图片服务；摄影预设需要联网，失败保留银灰背景。
- 下方牌组整合为一个圆角玻璃容器，封面更紧凑、信息对齐、两侧柔和淡出。每个任务只出现一次，浏览到首尾停止；浏览封面不改变当前任务或对话引用。
- 保留真实材料目录树、分组／四象限总览及原有展开看板；正文完整阅读，长内容自然增高。
- 工作对话可查找引用任务较早的进展，按关键词、问题与日期检索并跳回来源；模型设置支持 HTTP／HTTPS 自建服务。
- 快捷工具同步新的银灰折光、磨砂玻璃面板和圆角选中态，覆盖新建、进展、任务选择、一句话整理与模型设置；macOS／Windows 共用本地界面资源，保留图文草稿、提交回执和失败重试。

## 下载与升级

- Obsidian：`Tracelo-1.0.0-obsidian.zip`，包含 `main.js`、`manifest.json`、`styles.css`。
- macOS 13+：`Tracelo-Capture-1.0.0-macos-universal.zip`，支持 Apple Silicon／Intel。
- Windows 10/11 x64：`Tracelo-Capture-1.0.0-windows-x64.zip`，自包含 .NET，需 WebView2 Evergreen Runtime。

升级前备份，替换插件三件套并重载，保留 `data.json`、任务 Markdown、附件与快捷工具草稿。配套升级快捷工具。旧格式先备份后兼容迁移，不批量清理旧 Emoji 属性。布局与背景属于插件偏好，不作为正式进展追加到任务正文。

## 使用

点击“调整布局”显示所有插入与收回按钮；也可直接拖动左侧缩略图到行列插入点。插入加号支持选择模块，分界线支持方向键微调、Home 均分相邻两项。宽屏并排显示模块，窄屏顺排阅读。长内容优先完整显示，手动比例不截断正文。

顶栏图片按钮打开“背景设置”，支持 PNG／JPG／WebP／AVIF，最大 8 MB。预设摄影来源与许可见仓库设计说明；背景切换不改变任务、布局或草稿。
