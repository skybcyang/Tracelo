# Tracelo 0.9.0

搜索现在直接显示命中的内容和日期，并能跳转到原记录。窄窗口通过“任务／历史”切换查看内容，保留草稿与阅读位置。

## 本次更新

- 搜索结果标明当前名称、详情、历史名称或进展，突出显示关键词；已完成和异常关闭任务直接出现在结果中。点击历史命中定位原事件，点击当前名称或详情打开对应卡片。
- 无结果时说明搜索范围，提供清除搜索入口；同一任务的多处匹配可展开查看。
- 修复中文输入法选词被搜索刷新打断的问题：选词期间保留输入框，确认文字后再更新结果。
- 插件区域宽度不超过 900px 时使用“任务／历史”切换，无需滚过整个看板才能看历史；切换保留草稿和滚动位置，在历史页新建任务后自动显示新卡片。
- 进展和完成节点使用更清晰的色条与浅底，属性历史仍按原顺序完整保留。
- 移除展示模式及其保存设置；旧配置和备份中的展示模式字段会被忽略。单张卡片展开、看板缩放、顶部对齐和瀑布流布局继续保留。

## 下载与升级

| 文件 | 用途 |
| --- | --- |
| `Tracelo-0.9.0-obsidian.zip` | Obsidian 插件：main.js、manifest.json、styles.css |
| `Tracelo-Capture-0.9.0-macos-universal.zip` | macOS 13+，Apple Silicon 与 Intel |
| `Tracelo-Capture-0.9.0-windows-x64.zip` | Windows 10/11 x64，自带 .NET 8 |
| `SHA256SUMS.txt` | 下载文件 SHA-256 校验值 |

插件要求 Obsidian 1.8.0 或更新版本。替换 `.obsidian/plugins/work-timeline/` 中的三个插件文件并重载，保留 data.json、任务、材料和备份目录。任务存档继续使用 v1 协议，无需重建；桌面快捷工具的创建流程沿用 0.8.0，本次同步版本号并重新构建。

Windows 需要 WebView2 Evergreen Runtime；macOS 使用系统 WebKit。macOS 包仅作 ad-hoc 签名，尚未开发者签名／公证；Windows 程序尚未代码签名。

## 验证范围

发布流程要求插件单元、存档协议、浏览器布局与交互检查，以及 macOS Universal 打包／WebKit 检查、Windows 原生核心／窗口检查通过后才发布附件。输入法回归覆盖组合输入事件顺序、取消选词、确认后退格及英文输入；这些自动检查不替代所有系统输入法候选窗口、移动触屏和第三方主题的实机验证。

详见 [0.9.0 发布验收](https://github.com/skybcyang/Tracelo/blob/main/docs/validation/2026-09-28-release-090.md)与[桌面工具文档](https://github.com/skybcyang/Tracelo/blob/0.9.0/desktop/README.md)。
