入口与层级

卡牌使用统一的三段排列：顶部标题与菜单，中间最新进展，底部信息区。已有的待办／截止日期在底部信息区上行；分组与象限标签在下行左侧，更新时间在右侧。内边距12px、相邻信息行间距4px、区块间距8px，字体大小保持不变；没有可选信息时不显示空标签。展开后才提供“添加待办”“设置截止日期”；菜单也有相同入口。任务标题展开卡牌，右侧切换任务历史；日期标签打开编辑器，右侧“查看截止日”进入每日时间线。

待办是步骤，进展是记录

勾选、取消勾选、编辑、删除均保持卡牌位置，不覆盖最新进展。删除有撤销；全部勾选后不会自动结束主任务。正式进展仍按原流程记录后收起卡牌。

截止安排与已发生记录

时间线顶部的浅琥珀区域呈现当前安排；下方纵线只放实际事件。更改日期会移动截止标记并追加变更历史，清除日期后标记消失。已结束任务保留日期但不再显示逾期。

尺寸与状态

以一张基础卡牌为一格：同宽、148px基础高度、12px间距。普通内容占一格；内容增加时，自动使用容纳全部内容所需的最少整格，卡牌底边与旁边堆叠的普通卡牌对齐，不固定四格。两格308px、三格468px，继续增长时再增加格数。文字完整换行，清单随内容展开，统一由任务栏滚动。桌面清单行高32px，窄屏仍保留44px操作行高。≤1120px 左栏为单列；≤760px 时间线下移。蓝色表示操作和选择，琥珀表示临近截止，红色表示逾期，同时提供文字，不依赖颜色识别。

可操作范围

可以新建卡牌、选填两个功能、增删改勾选待办、记录进展、设置／清除日期、切换未来日期、结束／重开任务、搜索与切换视图。数据只存于当前页面内存，刷新或重置会恢复示例。拖动排序、异常关闭和真实存档不在此原型中。
