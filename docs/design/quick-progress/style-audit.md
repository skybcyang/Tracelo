# 两个快捷入口的视觉一致性

本次仅审视当前 mockup，未修改界面。

1. 记录进展：信息与操作完整。沿用看板紧凑密度，正文和操作偏小；白色卡片、整圈蓝色选中边框，外置草稿提示，和新建弹窗的外壳不同。
2. 新建任务：沿用原共享表单，输入层次清楚。淡蓝灰背景、较大的输入控件、顶部蓝色短线和固定底部操作栏，与进展页在容器与密度上不一致。

建议以原新建弹窗为快捷窗口的共同视觉基准。保留两个功能各自的内容结构，共享容器背景、边框、圆角、标题层级、控件尺寸、焦点与底部操作区。进展继续使用原卡片组件，通过统一的宽松密度配置调整到独立窗口场景，不建立第二套卡片实现。

建议起点：窗口宽 600px；内边距 20–24px；标题 18px、正文 14px、辅助文字 12px；主要按钮高 36–40px。进展输入可以比单行控件更高，不要求两种表单结构或全部字段高度一致。

限制：本次聚焦视觉一致性；小文字与小按钮是可见的阅读、点击风险，未进行完整对比度、缩放或辅助技术合规审计。
