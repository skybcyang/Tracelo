2026-09-29，新建的独立 HTML mockup。保留上一轮 A 项目卡片结构；原有设计目录和生产插件没有改动。

## 查看

在 `docs/design` 运行静态服务器，打开 `notion-cards/`。

当前预览：<http://127.0.0.1:4188/notion-cards/>

- `?screen=overview`：主界面、卡片展开、快捷新建、快捷推进的截图总览。
- `?screen=main`：项目卡片。
- `?screen=expanded`：默认展开第一项任务。
- `?screen=quick-create`：快捷新建，预填示例草稿。
- `?screen=quick-progress`：快捷推进，展示任务上下文。
- `?screen=detail`：任务历史。
- `?screen=calendar`：截止日历。
- 任一画面可追加 `&mode=dark` 和 `&width=430`。

独立页面为 `preview.html?screen=main&mode=light`，没有外层评审工具栏。

## 视觉与交互

面向日常使用的 Obsidian 插件窗格；克制、中性、信息优先。使用 Notion 风格作为视觉参考，不是官方组件或像素复制。继续使用项目已有的 Lucide 资源与系统字体。

- `DESIGN_VARIANCE=3 / MOTION_INTENSITY=2 / VISUAL_DENSITY=6`。
- 白色卡片、近白背景、深灰文字、细灰边；深色对应中性炭灰。
- 蓝色用于主要操作。柔和的蓝、棕、灰紫分组标签与红、黄、蓝、灰优先级标签有明确语义，不染整张卡片。
- 卡片 6px、控件 4px、浮窗 10px 圆角；阴影只辅助边界。
- 点击任务在原卡片展开说明、待办、进展输入及历史入口。
- 快捷新建先展示名称、背景、分组与截止；优先级、待办、初始进展和附件按需展开。
- 快捷推进显示上次进展，独立输入新进展，可以切换任务并保留当前会话中的草稿。
- 完成任务提供撤销；空内容保存给出就地提示。
- 760px 以下两列，560px 以下单列。窄窗保留搜索、新建、快捷记录和更多工具。
- 仅短暂的 hover / pressed 反馈，遵循减少动态效果设置。

## 演示范围

可操作：分组/今日筛选、搜索与空状态、新建、待办勾选、记录进展、查看/编辑详情、完成/撤销、历史、归档恢复、四象限、截止日历、快捷窗口切换任务、快捷键保存。

仅内存中的示例任务，不读写 Obsidian vault，不与桌面工具同步。切换画面、明暗、窄窗或刷新会重置当前 iframe 数据。示例日期固定在 2026-09-29。图片仅在当前表单预览，不会保存到任务历史。不包含拖动重排、真实文件持久化或跨窗口草稿同步。

`base.css` 为上一轮共享样式的独立快照；`preview.js` 从已有演示逻辑裁剪并调整，避免改变旧版本。`notion.css` 负责这版的视觉规格。
