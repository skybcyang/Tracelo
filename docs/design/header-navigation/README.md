# 顶栏导航层级设计

> 这是 2026-09-29 的历史原型。0.9.3 已移除右上角快捷记录图标，分组放不下时收入“更多分组”，不再沿用下文“全部标签换行”的取舍。当前行为见[导航验证](../../validation/2026-09-30-navigation.md)。

预览：http://127.0.0.1:4188/header-navigation/

仅新增设计稿，沿用 plugin-collection 的配色、卡片和时间线。没有修改或安装生产插件。

## 结构

- 上层是全局工具：品牌、搜索、快捷工具、截止日历、系统设置。
- 下层是任务操作：分组看板 / 四象限、可见分组标签、管理分组、新建任务。
- 标签直接展示全部、产品研发、日常工作、个人计划、未分组及进行中数量。选中项使用主题色下划线。
- 展示方式和分组筛选互相独立；切换四象限保留分组。选中某个分组后，新建任务默认归入该组。
- 宽窗口中下层为一行；分屏时分组标签独占一行；标签放不下时自动换行，不使用下拉菜单或“更多”隐藏分组。
- 右侧仍是全局每日时间线。窄于 780px 时用任务 / 时间线切换，避免把卡片挤得过窄。
- A 矿物绿、D 石墨紫、E 冰川蓝、F 暖白朱砂共用同一导航结构。

## 预览边界

全部为示例数据，刷新恢复。宽度、主题与多分组开关是设计评审工具，不属于插件界面。大量分组展开会增加头部高度，这是本方案对“分组直接可见”的取舍。
