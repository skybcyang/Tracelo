# Afterglow / 霓虹版

完整可交互 mockup，默认墨蓝深色；支持浅色切换。荧光青主操作、紫粉分组、发光边缘、时间线光点与低幅呼吸动画。

运行与验证记录见 [三款方案说明](../variants/README.md)，页面对比见 [对比入口](../variants/index.html)。

`index.html` 是交互入口，`variant.css` 是该方案的设计层，`01` 至 `14` PNG 是浏览器截图。`?screen=create|detail|quick|search|transfer|groups` 可直接打开弹窗；`?page=timeline|archive|settings` 打开页面；`?view=quadrant` 打开四象限；`?theme=light` 打开浅色。

示例数据仅保留在当前页面会话，刷新恢复，不接入正式插件。减少动态效果设置下关闭呼吸与位移动画。
