# 当前卡片动效实现说明

2026-09-30。采用用户确认的 `tracelo-card-motion.html` 中的轻聚焦、连续高度、进度比例和新增记录反馈；沿用正式界面的主题、卡片结构与稳定列顺序。

## 依赖与接入

卡片信息展开、编辑状态和默认等高先由卡片渲染与 CSS 决定。动效层只连接渲染前后的显示结果，不决定业务状态、不提交数据、不移动焦点、不写滚动位置。

`captureViewMotion(root)` 必须在改变根类名、替换 DOM 之前执行，捕捉过程只读，不取消动画或改变后续阅读锚点测量。完成渲染、稳定列挂载和阅读位置恢复之后，调用 `animateViewMotion(root, snapshot, { eventIds, anchorTaskId })`。`eventIds` 传所有任务的完整事件 ID 集合，首次渲染也调用，以区别“新写入的记录”和“切换历史后首次出现在屏幕的旧记录”。`anchorTaskId` 传当前阅读卡片 ID。待办行提供 `data-todo-id`，相同文案的待办依然可以独立反馈。

卡片高度使用实际 CSS 像素值（不叠加看板缩放）在 240ms 内变化，文本不做整体缩放。瀑布流沿现有稳定列自然让位，不重新按高度排卡。快速反向操作先读取当前动画中的高度与不透明度，再取消旧动画，从实际中间值开始下一次；结束后不遗留固定高度。详情、待办与输入区仅在新显示时分层淡入。

仅为原任务视口中可见卡片创建动效。阅读锚点上方的卡片直接落到最终高度，不在主视图纠正滚动后再次挤动锚点；当前卡片和下方可见卡片仍连续变化。这样大量卡片的模式切换不会同时运行数百个高度动画，也无需持续纠正滚动或拦截用户滚轮。

轻聚焦由 `has-focused-task` 和 `.is-selected` 控制；其他卡片保持 76% 不透明度，悬停或键盘焦点恢复清晰，保留点击操作。重绘时只为不透明度真正变化的卡片补 180ms 交接，勾选或输入不会重播全看板明暗。

进度环从上次实际 `stroke-dasharray` 过渡至新比例；只有完成最后一项时，计数芯片做一次最大 1.045 倍的轻确认。待办行比较已保存文本状态而非事件中已提前变更的 checkbox 值。任务结束与异常关闭仍由原业务操作决定。

新增时间线记录只淡入新增正文、出现新节点，并绘制该节点的短连接线，旧记录和旧连接线不重播。连接线是无交互的装饰节点，动画完成或取消后移除；不承担业务状态。

## 现有反馈盘点与取舍

| 场景 | 当前基线 | 本轮采用或暂缓 |
| --- | --- | --- |
| 卡片悬停与选中 | 160ms 边框、背景、阴影过渡 | 保留，增加跨重绘高度、轻聚焦与状态差值反馈 |
| 稳定瀑布流 | 固定列分配，原位自然流 | 保留；高度动画驱动同列让位，不引入按高度重新排序 |
| 拖拽 | 原生拖拽，拖动透明度、目标边框、区块落点反馈 | 采用既有落点预览；暂缓抬起缩放与跨区归位动画，避免原生拖拽预览和真实卡片重复移动，以及虚构未确认的保存结果 |
| 搜索定位 | 命中文字标记、目标焦点描边、准确滚动定位 | 采用现有持续定位高亮；暂缓跳动或闪烁，避免在长记录阅读中抢注意力 |
| 图片预览 | 等比例图片、原生 dialog、遮罩、关闭与 Esc | 保留现有可靠预览；暂缓原位共享元素缩放，因历史图片异步加载、跨滚动容器和原生 dialog 顶层坐标需单独验证，不能牺牲焦点及关闭可靠性 |
| 记录成功 | `recordedTaskId` 提供实际落盘后的状态文字 | 保留真实确认；新增时间线反馈跟随完整事件集合差值，不用动画完成事件决定成功 |

系统减少动态效果在开始时直接跳过所有 WAAPI；用户在播放中开启该设置也立即取消当前动效并显示最终状态。监听器与临时连接线在动画完成或取消后清理。无需等待 `animationend`；任何业务写入、窗口关闭、任务结束均独立于动效。

## 验证范围

`node tests/view-motion.browser.mjs` 的九项检查覆盖浏览器真实 WAAPI 高度插值、同列邻卡位置、另一列稳定、动画中途反向、只读捕捉不改变锚点测量、可读可点的轻聚焦、无关卡片不重播、进度环比例、最后项不结束任务、新旧事件区分、状态局部反馈及播放中启用减少动态效果。100 卡中部阅读测试验证动画数量仅限可见范围，锚点在动画前、中、后保持相同偏移。开发时先运行空实现得到对应行为失败，再实现并获得通过；锚点与百卡场景也分别先证实原实现失败，再修正通过。

该独立测试验证动画机制；真实 Obsidian 与桌面快捷工具实机表现、中文输入和跨端窗口生命周期仍由整体验收记录单独说明，不能由该测试推定已完成。
