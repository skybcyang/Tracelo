## 四款独立结构

| 方向 | 信息组织与编辑 | 快捷工具 | 取舍 |
| --- | --- | --- | --- |
| A 项目卡片 | 按项目分栏，最新进展始终可见，待办与输入在卡片原处展开；取消常驻时间线侧栏 | 直接填写，元数据在输入下方 | 多项目容易比较，任务多时纵向滚动较多 |
| B 任务调度台 | 扁平任务列表 + 固定详情区，列表可按截止排序、筛今天、方向键切换 | 搜索任务 → 确认上下文 → 输入记录 | 大量任务切换快；窄窗格切换列表与详情 |
| C 今日推进 | 按日的进展时间流 + 今天截止队列，底部固定接续输入；默认展示最近三条，可展开更早记录 | 上次进展 → 这次进展，可同时完成任务 | 适合连续记录和回顾；跨项目盘点需要选择任务 |
| D 清单聚焦 | 今天 / 全部任务，单列条目，只展开当前任务；新建固定在底栏 | 名称、备注、保存优先，日期和属性按需展开 | 适合 Obsidian 窄窗格与低干扰工作；同时比较多个任务细节较弱 |

颜色与结构分开：A 默认矿物绿，B 默认宝马工业，C 默认霓虹余辉，D 默认冰川蓝。每款都可切换前一轮的六种色板和深浅模式。比较页的“统一配色比较”将四款主界面和八个快捷窗口全部换为冰川蓝浅色，便于排除颜色影响。BMW M 为配色启发，非官方设计系统。

## Things 3 参考如何落地

实际查看了官方功能页、Today 的 Mac 界面图、Quick Entry 与 Slim Mode 说明：

- [功能与任务展开](https://culturedcode.com/things/features/)：任务就地展开，次要字段按需出现。对应 D 的单列任务展开，以及快捷工具的可选属性。
- [Today Mac 界面参考图](https://static.culturedcode.com/things/videos/2017-05-18-website-videos/2-today-mac.png)：用标题、留白与小尺寸元信息构成层级。D 的默认界面无永久详情面板，未选中的任务保持轻量。
- [Quick Entry](https://culturedcode.com/things/support/articles/2249437/)：快速录入后返回手头工作。D 快捷创建优先留出名称与备注，其他属性单独展开；B 保留任务搜索作为另一条路径。
- [Slim Mode](https://culturedcode.com/things/support/articles/3238254/)：隐藏应用侧栏，专注当前列表。四款均不复制独立应用侧栏；D 的宽窄窗口使用同一单列结构。

参考的是交互与层级，不是像素复刻。没有新增 Things 的提醒、重复任务、日历事件同步或完整 GTD 体系。“今天”在这里按 Tracelo 已有的截止日期筛选，并非复制 Things 的开始日期模型。C 仍保留 Tracelo 的追加式进展时间线。

## 实现与状态边界

原生 HTML/CSS/JS，无新依赖；复用前一轮的语义色板和已有本地 Lucide。设计仅在本目录，正式插件、桌面工具及用户笔记库均不在这轮改动范围。

用户可操作：搜索与清空、筛选、卡片或条目展开、切换任务、勾选待办、记录进展、快捷新建、编辑任务、完成与撤销、归档重新打开、选择截止日、查看四象限和历史。快捷进展草稿按任务隔离，切换后返回仍在；收起快捷窗口后可重新打开继续。

示例日期固定为 2026-09-29，周二；新记录演示时间固定为 14:36。所有修改仅存于当前页面内存，刷新、切换评审页面或重新加载 iframe 后恢复示例数据。未接入真实文件保存、系统级快捷键、Obsidian API 或同步。图片控件只在当前输入中本地预览，不上传，也未接入进展记录的附件持久化。

键盘：主界面 N 新建；B 列表方向键切换；B 快捷搜索方向键选择、Enter 进入；表单 Cmd/Ctrl + Enter 保存；Escape 关闭弹窗或收起快捷工具。窄窗格隐藏工具栏搜索，常用操作可从“更多工具”进入。触控目标仍按桌面插件密度取舍，未声明达到移动端原生应用标准。

## 设计判断

taste 用于风格保留、配色与形状一致性。密集工具不适用营销页布局规则；本轮由 interaction-design 和 ui-density 指导操作和密度。Product Design 的 ideate 用于区分结构与交互；环境无图片生成工具，沿用用户已授权的交互 HTML mockup 方式。

全局 MOTION_INTENSITY=3，只保留按压反馈与局部静态辉光，遵循 reduced motion。A / B / C / D 的 DESIGN_VARIANCE 分别为 5 / 4 / 6 / 3，VISUAL_DENSITY 分别为 6 / 8 / 6 / 4。B 硬边和三色线、C 多强调色与辉光来自用户明确要求。D 用间距和层级降低阅读负担，不以装饰图或仪表盘补满空白。

## 验证记录

- Node 语法检查：preview.js、gallery.js。
- 宽窗格 1100×740：四款主界面、八个快捷窗口、同色版本全部检查，无文档横向溢出；四款另一种明暗模式另存截图。
- 窄窗格 430×812：四款主界面和快捷记录均无文档横向溢出。B 实际切换任务详情并返回列表；D 另检查 375×812 展开状态。
- 实际操作：D 主界面记录、新建回到列表、完成与撤销、搜索空状态恢复；日历切到 9月30日显示客户反馈；C 展开更早记录、切空日期并返回、快捷草稿隔离、记录同时完成；B 搜索、Enter 进入、空输入提示、Ctrl+Enter 保存、方向键切换任务。
- 所有截图保存在 screenshots/。quick 的 -frame 原始截图使用正常视口捕获，再按实测 DOM 边界裁切；本机浏览器 clip 截图存在缩放异常，因此不使用它作为交付图。
- make-overview.py 只裁切和拼接截图，不重画 UI，不拉伸比例。
