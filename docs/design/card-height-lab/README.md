# 卡片高度单位：可行性探索

2026-09-29。仅独立样机，没有修改生产布局或本机插件。沿用真实任务卡片组件、现有主题和临时内存仓库，加入高度量化与稳定分列实验层。

运行：在仓库根目录执行 `node docs/design/card-height-lab/server.mjs`，打开 http://127.0.0.1:4191 。顶部切换自然高度、大单位、动态小单位；可点击真实任务卡片展开、编辑临时草稿，并使用长图、长文本和参考线按钮。刷新会重置全部临时内容。

## 结论

可行，推荐“随卡宽分档的小单位 + 向上取整 + 稳定列”。同一组共享单位；单位只随卡宽所在档位改变，不随内容或每次输入改变。内容增长时卡片升档，下面的卡片在本列顺延。保留当前分组分区、主题、导航和时间线。

原 0.5.0 的 148px 整格和 `row dense` 是两件事：前者控制高度，后者可能将后面的卡片填入前面的空洞。本实验保留倍数高度思想，但没有恢复跨列稠密重排。`interaction-design` 对位置稳定、草稿保留和非阻塞反馈的要求用于评估取舍。

## 实测对照

12 张相同临时任务卡，1280px 窗口，卡宽 318px、间距 12px。所有方案使用相同的自然内容测量和列顺序。额外留白为量化后高度减去当前可见内容的自然高度；不是包含所有列尾空白的整体空间利用率。

| 方案 | 高度规则 | 平均额外留白 / 卡 | 最大额外留白 / 卡 |
| --- | --- | --- | --- |
| 自然高度 | 随内容 | 0px | 0px |
| 旧式大单位 | 148 / 308 / 468… | 103.7px | 158.1px |
| 动态小单位 | 当前为 28px 单位 + 12px 间距 | 20.4px | 38.1px |

固定为 280px 则这批样本有 8/12 张的自然内容高度超过上限，必须摘要折叠、内部滚动或另外打开完整内容，无法同时固定高度并直接完整展示。这里只根据实际内容测量推导，没有将固定裁切方案做成正式交互。

样机规则：卡宽小于 290px 用 24px 单位，290–339px 用 28px，340px 及以上用 32px。阈值为探索参数，不是已定稿设计。高度包含间距补偿：

`卡片高度 = ceil((内容高度 + 间距) / (单位 + 间距)) × (单位 + 间距) − 间距`

例如单位 28px、间距 12px，实际卡高为 148、188、228、268、308、348…；这样两张较小卡片加中间间距也能落在同一网格线上。不是简单把卡片高度乘以整数、忽略间距。

## 实际操作验证

- 1280px 展开首张卡：228 → 428px；同组其他列的卡片未移动，无重叠。
- 1280px 加载 600×900 实验长图：首张卡 228 → 668px；同组其他列位移为 0，无重叠，卡片高度容纳完整内容。
- 960px 和 390px 下同时加入长图与长文本：无横向页面溢出、无卡片重叠；卡片高度均容纳当前可见内容。长内容会让整张卡片变高，这是保留完整内容的代价。
- 展开输入临时草稿，切换大小单位并从 390px 调回 1280px：草稿保留。
- 窄屏同一组仍共享同一单位；改变列数时重新分列。

## 正式实现前需要收敛的细节

1. 不承诺每列末尾完全齐平。保持顺序、完整内容、零空白、列尾完全齐平无法同时保证；不应用额外拉长所有卡片来伪造整齐。
2. 普通态使用统一档位；编辑态建议优先让输入内容自然增长，结束编辑后再归档，避免输入时不断升降档。样机目前也会量化展开卡，供比较。
3. 缩小高度应在编辑结束或收起后统一处理；正式实现应增加阈值余量，避免临界值抖动。列宽临界点也应加滞回或在调整窗口结束后稳定计算。
4. 如加入移动过渡，只对受影响卡片做短暂位移过渡，尊重减少动态效果设置；本样机没有新增位移动画。
5. 当前为浏览器中的真实组件探索，未安装到 Obsidian。尚未进行真实宿主、系统大字号、拖拽全过程、全部主题和性能压力验收；现有生产版的原测试不能替代这些后续检查。
