# 内容自适应卡片

第八批需求取代 0.5.0 的 148px 整格高度与稠密补位规则。

自然高度规则已发布于 0.6.0；下述图标选择器、标题操作区、顶栏与任务详情优化为 2026-09-28 的后续工作区改动，尚未发布。

- 默认“顶部对齐”：CSS Grid 按行排列，同列宽、顶部对齐、各卡自然高度；下一行从上一行最高卡片下方开始。视觉顺序与 DOM、键盘阅读和拖动保存顺序一致。
- “设置 → Tracelo → 卡片布局”可切换“顶部对齐（默认）”和“瀑布流”。瀑布流仍然等宽，将原任务顺序依次分配到各列，每列独立向下排列；展开、收起或图片加载只影响本列，不按高度重新分配卡片。窗口或缩放改变列数时重新分列。瀑布流的 DOM／键盘顺序沿每列向下，拖动仍使用既有任务排序；切换布局不改写任务顺序。
- 100% 时最小卡宽 260px，卡间距 12px，中性边框 1px，圆角 12px，内边距 18px、底部 20px。弱网格画布、独立卡面、轻阴影；深色主题有独立表面与边框色。
- 悬停微调边框，不上浮；选中边框对应右侧任务历史，与是否展开独立。
- 收起：标题最多 2 行，最近进展最多 3 行，前三项未完成待办各最多 2 行；其余待办显示数量入口。实际被截断时显示“展开完整内容”，短内容不出现该入口。
- 已完成待办在原卡片内折叠查看；勾选后重新计算未完成摘要、剩余数量和进度环。完成分数只在进度环保留一处；完成组标题说明组内数量。
- 标题行保留可点击的任务图标、标题、改名和更多；桌面图标按钮统一为 24px，图形为 16px。文件夹和空详情入口移到下方状态栏；没有待办或截止日期时并入元信息行，不占独立空行。有详情时直接展示内容，并提供“编辑详情”入口。
- 直接点击任务图标或「更多 → 更换图标…」可搜索 Obsidian 内置图标并查看预览；常用分类支持中文，其余使用英文名称。支持继承分组和隐藏图标，分组管理复用同一选择器。规范化宿主返回的 `lucide-` 前缀，兼容旧图标名称。
- 详情、最新进展、待办和进展输入的辅助标题统一为 11px、600 字重和弱化颜色；长待办的复选框对齐首行。进展输入底部将草稿提示、收起和提交排在同一行，桌面按钮等高 30px，粗指针设备为 44px。
- 详情在普通模式收起态也完整展示，文字不截断，图片按比例显示完整高度。展开与展示模式另外显示完整标题、进展和待办；所有完整阅读入口复用原卡片展开状态，没有另一套详情面板或卡内滚动区。
- 截止日期、标签和进展时间沿用现有语义；修改属性不改变最近进展的实际时间。输入、图片、链接、清单、菜单、文字选择和拖动继续隔离事件。

自动验收以生产渲染与宿主样式夹具测量内容高度、裁切、重叠、等宽和顺序，覆盖深浅色、窄屏／多列、两种视图、60%／100%／120% 及普通／展示模式。真实宿主与硬件限制见[集成验收](../validation/2026-09-28-integration.md)。

后续布局与图标专项证据见[卡片优化验收](../validation/2026-09-28-card-polish.md)。

## 顶栏显示设置（后续工作区改动）

顶栏左侧为品牌与任务统计，中间依次为「分组／四象限」「展示模式」「− / 比例 / ＋」，右侧保留导入导出、分组管理和新建任务。细分隔线区分视图切换与显示设置；取消底栏，归还内容高度。容器宽度不足 1200px 时显示设置独占顶栏第二行，600px 以下进一步换行，避免控件挤压或遮挡内容。

缩放使用统一的「− / 比例 / ＋」组合，固定比例栏宽度与等宽数字；范围仍为 60%～120%，步长 5%，点击比例恢复 100%，悬停提示说明操作。只缩放看板，工具栏和时间线保持原尺寸。按钮支持连续键盘操作，边界按钮禁用后将焦点转到重置；粗指针设备使用 44px 点击高度。颜色沿用现有主题变量，深浅色均单独验证。

展示模式、缩放和分组／四象限切换只更新顶栏与左侧看板，复用右侧时间线节点；保留时间线日期、任务选择、属性历史折叠状态和滚动位置。任务数据变化仍正常刷新相关内容。

卡片布局设置同样只刷新看板，保留当前展开卡片和进展草稿。此偏好适用于分组、四象限和已结束区，与展示模式相互独立；保存后重开继续生效。旧数据或未知配置默认为顶部对齐。空仓库导入时恢复包中的布局，已有任务的仓库导入时保留本地布局。

## 任务详情

产品界面统一使用“详情”，创建表单在标题之后提供可选的多行输入框，支持 Markdown。创建时填写的详情随任务一并保存，只生成创建事件，不伪造进展或额外的详情变更事件；保存失败保留输入以便重试。现有图片粘贴、上传、拖入及独立预览能力保留在卡片详情编辑器中。

内部 JSON 字段 `notes` 和事件类型 `notes_changed` 保持稳定，新存档正文标题为 `## 详情`。读取同时接受完整规范的旧 `## 备注` 正文及旧“备注变更”事件标签，不就地改写旧文件，也不放宽对手动修改正文的校验。macOS 快捷创建同步输出新格式。
