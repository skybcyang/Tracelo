# 内容自适应卡片

> 此文保留 0.6.0～0.9.1 的历次设计规则，不作为 0.9.3 的尺寸验收基线。当前以[需求文档](../requirements.md)、[展示模式](presentation-mode.md)和[0.9.3 发布说明](../releases/0.9.3.md)为准。

0.9.3 当前要点：默认收起卡片等高，标题单行、最新进展固定两行；详情与完整待办在展开或展示模式中显示。展示模式完整阅读全部卡片，编辑仍限一张。分组上下排列、组内横向铺卡，保留顶部对齐／稳定瀑布流；时间线最新在上。四主题覆盖菜单，分组溢出收入下拉。下文旧尺寸、蓝灰色、前三项待办和底部最新等规则按历史版本阅读。

2026-09-29 后续调整：恢复分组上下分区、组内横向自适应铺卡，保留新版主题与导航。原顶部对齐／稳定瀑布流再次作用于多列卡片；恢复的是下述自然高度布局，不回退到 0.5.0 的整格稠密补位。

第八批需求取代 0.5.0 的 148px 整格高度与稠密补位规则。

自然高度规则发布于 0.6.0；图标选择器、顶栏、任务详情与布局偏好纳入 0.7.0。0.8.0 精简操作区并将分组／象限移入二级菜单。0.9.0 曾移除旧展示模式；2026-09-29 的整合随后发布为 0.9.1，0.9.3 重新实现阅读／编辑分离的展示模式。

- 默认“顶部对齐”：CSS Grid 按行排列，同列宽、顶部对齐、各卡自然高度；下一行从上一行最高卡片下方开始。视觉顺序与 DOM、键盘阅读和拖动保存顺序一致。
- “设置 → Tracelo → 卡片布局”可切换“顶部对齐（默认）”和“瀑布流”。瀑布流仍然等宽，将原任务顺序依次分配到各列，每列独立向下排列；展开、收起或图片加载只影响本列，不按高度重新分配卡片。窗口或缩放改变列数时重新分列。瀑布流的 DOM／键盘顺序沿每列向下，拖动仍使用既有任务排序；切换布局不改写任务顺序。
- 100% 时最小卡宽 260px，卡间距 12px，中性边框 1px，圆角 12px，内边距 18px、底部 20px。弱网格画布、独立卡面、轻阴影；深色主题有独立表面与边框色。
- 悬停微调边框，不上浮；选中边框对应右侧任务历史。点击卡片展开时切换到该任务历史，再次点击主动收起时回到全部任务的每日时间线。
- 收起：标题最多 2 行，最近进展最多 3 行，前三项未完成待办各最多 2 行；其余待办显示数量入口。实际被截断时显示“展开完整内容”，短内容不出现该入口。
- 已完成待办在原卡片内折叠查看；勾选后重新计算未完成摘要、剩余数量和进度环。完成分数只在进度环保留一处；完成组标题说明组内数量。
- 标题行保留用于识别的任务图标、可点击标题和更多；图标修改与改名统一收进右键／更多菜单。桌面图标区域统一为 24px，图形为 16px。标题为 16px、700 字重；标题下依次呈现截止提示、最新进展、完整详情和待办。截止日期明确写“截止”，今天和逾期用文字及对应颜色提示，结束任务取消紧迫状态。待办进度留在底部摘要行；底栏左侧固定为分组、状态，右侧固定为带“进展／创建”含义的时间，当天加“今天”。左侧可换行，时间不参与挤压和重排；缺少可选字段不留空行。详情不额外增加“详情／编辑详情”标题行。
- 「更多 → 更换图标…」可搜索 Obsidian 内置图标并查看预览；常用分类支持中文，其余使用英文名称。支持继承分组和隐藏图标，分组管理复用同一选择器。规范化宿主返回的 `lucide-` 前缀，兼容旧图标名称。取消或保存后焦点回到更多按钮。
- 最新进展正文为 13px 和主文字色，辅助标题为 11px、600 字重；当天实际记录的进展显示蓝色“最新进展 · 今天”，修改详情或属性不冒充新进展。待办和进展输入的辅助标题继续弱化，长待办复选框对齐首行。进展输入底部仅保留靠右的收起和提交按钮，桌面按钮等高 30px，粗指针设备为 44px。自动保留草稿行为不变。
- 详情在收起态也完整展示，文字不截断，图片按比例显示完整高度。展开后另外显示完整标题、进展和待办；所有完整阅读入口复用原卡片展开状态，没有另一套详情面板或卡内滚动区。
- 截止日期、标签和进展时间沿用现有语义；修改属性不改变最近进展的实际时间。输入、图片、链接、清单、菜单、文字选择和拖动继续隔离事件。
- 选中卡片显示“正在查看历史”，与右侧任务历史标题区共用蓝色边线提示。通过标题、卡片正文、收起按钮或非输入法组合状态的 Escape 主动收起时，取消任务选择并回到原先日期的全部任务时间线，草稿保留。已有草稿或详情正在编辑时继续防止正文误点；图片、链接、清单等交互不会触发收起。长卡片收起后，如标题上沿已经被滚出视口，则将卡片顶部滚回可见范围；标题本来可见时保留阅读位置。

自动验收以生产渲染与宿主样式夹具测量内容高度、裁切、重叠、等宽和顺序，覆盖深浅色、窄屏／多列、两种视图、60%／100%／120% 及卡片收起／展开。真实宿主与硬件限制见[集成验收](../validation/2026-09-28-integration.md)。

后续布局与图标专项证据见[卡片优化验收](../validation/2026-09-28-card-polish.md)。

## 顶栏显示设置（后续工作区改动）

顶栏左侧为品牌与任务统计，中间依次为「分组／四象限」「− / 比例 / ＋」，右侧保留导入导出、分组管理和新建任务。细分隔线区分视图切换与显示设置；取消底栏，归还内容高度。容器宽度不足 1200px 时显示设置独占顶栏第二行，600px 以下进一步换行，避免控件挤压或遮挡内容。

缩放使用统一的「− / 比例 / ＋」组合，固定比例栏宽度与等宽数字；范围仍为 60%～120%，步长 5%，点击比例恢复 100%，悬停提示说明操作。只缩放看板，工具栏和时间线保持原尺寸。按钮支持连续键盘操作，边界按钮禁用后将焦点转到重置；粗指针设备使用 44px 点击高度。颜色沿用现有主题变量，深浅色均单独验证。

缩放和分组／四象限切换只更新顶栏与左侧看板，复用右侧时间线节点；保留时间线日期、任务选择和滚动位置。0.7.0 起属性历史逐条显示，不再折叠。任务数据变化仍正常刷新相关内容。

卡片布局设置同样只刷新看板，保留当前展开卡片和进展草稿。此偏好适用于分组、四象限和已结束区；保存后重开继续生效。旧数据或未知配置默认为顶部对齐。空仓库导入时恢复包中的布局，已有任务的仓库导入时保留本地布局。

## 任务详情

当前工作区的右键和更多按钮共用一套任务菜单：改名、图标、添加／编辑详情、分组、象限、截止日期、文件夹及生命周期操作；进行中的任务另提供记录进展和添加待办。结束的任务保留详情编辑与重新打开，隐藏进展／待办新增操作。详情编辑复用原卡片编辑器，保留图片、草稿、保存失败重试和取消行为；未保存的详情通过轻量状态文字提示。

一级菜单中的“分组”“象限”只作二级菜单入口；各分组名称（含未分组）和四个象限分别放入对应子菜单，当前值显示勾选标记。优先使用宿主原生子菜单；缺少该接口的旧宿主点击入口打开对应选项菜单，仍不平铺一级列表。

产品界面统一使用“详情”，创建表单在标题之后提供可选的多行输入框，支持 Markdown。创建时填写的详情随任务一并保存，只生成创建事件，不伪造进展或额外的详情变更事件；保存失败保留输入以便重试。现有图片粘贴、上传、拖入及独立预览能力保留在卡片详情编辑器中。

内部 JSON 字段 `notes` 和事件类型 `notes_changed` 保持稳定，新存档正文标题为 `## 详情`。读取同时接受完整规范的旧 `## 备注` 正文及旧“备注变更”事件标签，不就地改写旧文件，也不放宽对手动修改正文的校验。macOS 快捷创建同步输出新格式。
