## 设计选择

设计沿用 taste skill 中“一致视觉语言、真实内容、清晰层级、完整状态”的原则。该技能主要面向展示网站，这里按桌面工作工具的密度应用，不把任务看板改成营销落地页。用户明确要求的霓虹辉光优先于该技能的默认克制配色。工业版同时应用 industrial-brutalist-ui 的直角、规则线、等宽元数据与网格原则。

### Motorsport / 宝马配色工业风

金属灰工作区、深海军蓝主操作、浅蓝/深蓝/红三色。采用硬边卡片、三色分组线、方形时间线节点、紧凑字重和等宽统计数字。统计条实时反映进行中任务、当天截止和当天进展数量。默认浅色，并保留深色版本。

配色关系参考 [BMW M 官方品牌色说明](https://www.bmw-m.com/en/topics/magazine-article-pool/die-geschichte-des-bmw-m-logos.html)。色值是为界面重新调配的近似色，并非官方品牌 token；产品名称和图标仍属于 Tracelo，没有使用宝马徽标。

### Afterglow / 霓虹辉光

墨蓝背景，荧光青主操作，紫/粉区分分组。侧栏选中态带光边，任务卡片顶部有细光线，悬停强化对应分组色辉光，详情抽屉和弹窗带柔和外发光，时间线使用光点。摘要光点有 4 秒低幅呼吸动画。正文保持清晰，不做文字闪烁。默认深色，另有浅色版本。

系统启用 `prefers-reduced-motion` 时关闭动画和位移动效。保留清晰焦点边框、原生表单与对话框行为。

## 功能与实现边界

两套均继承松绿原型中的分组看板、四象限、拖动、筛选/排序/缩放、详情、待办、进展、完成/异常关闭/重开、新建、快捷记录、搜索、分组管理、时间线、设置及示例数据导入导出界面。每套有 14 张截图，覆盖主要页面、375 px 窄屏、另一种明暗模式。

各目录保有独立的 `index.html`、`studio.js`、`studio.css` 和 `variant.css`，后续任一方案可以继续修改而不影响原版。使用原生 HTML/JS/CSS 和已有 Lucide 图标；未引入或声称使用 React、Motion、GSAP。

数据仅在页面内存中；刷新后恢复示例数据。示例导出格式不是正式插件存档。图片材料只在当前会话预览。界面中的本地目录和备份提示是设计展示，不具备真正的 Obsidian 文件系统能力。
