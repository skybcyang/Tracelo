# 银灰工作台的品牌、字体与图标

2026-10-16。用户询问现有品牌图标与字体是否应适配新风格，随后确认按减轻品牌重量、统一操作图标和文字层级的方向实施。

## 视觉规则

- 品牌保留「T＋轨迹点」身份，用半透明银灰底、细边和更轻的笔画替代黑色实心底；深色外观使用浅灰字形。品牌保持中性色，不跟随主题强调色。
- Tracelo 字标使用系统无衬线字体，降低字重、放松原有紧字距，按小尺寸重新协调图标大小和间距。字体不依赖网络加载。
- 界面继续尊重 Obsidian 的 `--font-interface`；未配置时回退到系统界面字体与中文无衬线字体。标题、控件标签、普通正文分层；正文不使用细体，不修改用户 Markdown 的强调语义。
- 操作沿用现有 Lucide 体系，统一圆头、圆角连接与线宽，保持各控件既有尺寸和点击区域。品牌 SVG 独立于操作图标规则，图片和用户材料不受影响。
- 高对比度偏好加强操作图标与品牌边框；独立外观优先于宿主明暗。插件、共享创建／进展表单、菜单和 macOS／Windows 共用资源使用相同规则。

## 实现与证据

共用品牌生成器在 [src/brand.ts](../../src/brand.ts)，文字与图标 token 在 [styles.css](../../styles.css)，原生快捷标题比例在 [capture.css](../../desktop/Sources/TraceloCapture/Resources/capture.css)。没有更改任务协议或加入外部字体包。

本轮实际渲染、原生检查、本地安装与未测范围见[验收记录](../validation/2026-10-16-brand-type.md)。系统菜单栏与系统托盘仍采用既有原生入口图标。
