# Tracelo：六款插件与快捷工具 mockup

2026-09-29。当前方向是保留原三款设计的性格，收缩到插件尺度；不是重画成 Obsidian 默认皮肤。

## 打开

[六款总览](index.html)提供插件主界面、快捷新建、快捷进展的横向比较。点开一款后，可以切换八个界面、六套配色、深浅模式和窄窗口。收藏仅保存在当前浏览器中。

静态总览图：[插件主界面](overview.png) · [快捷新建](quick-overview.png) · [快捷进展](progress-overview.png)。三张图均由实际浏览器截图拼接，方便离线查看与讨论。

在仓库根目录运行：

```sh
python3 -m http.server 4188 --bind 127.0.0.1 --directory docs/design
```

打开 `http://127.0.0.1:4188/plugin-collection/`。无构建步骤，无外部字体或网络依赖；Lucide 复用相邻 `quick-progress/` 中的本地文件。正式插件源码、桌面程序和真实 vault 均未修改。

## 尺度与交互

从原版保留任务内容、三分组看板、四象限、最新进展、待办和时间线，取消独立应用侧栏、头像、首页大标题与统计区。插件顶部只保留紧凑品牌、搜索和高频动作。正文维持 12px，任务名称 14px，辅助信息 10-11px；没有整体缩放字体来假装“插件化”。

右侧时间线固定为辅助区域，卡片内展开输入进展；选中任务后时间线切换为该任务历史。780px 以下切换为任务／时间线两面板；窄到 480px 以下为单列任务。

快捷工具采用同一套色彩和控件规则，窗口约 554px 宽：

- 新建任务：名称、详情、分组、截止日期、四项优先级；待办和初始进展按需展开。
- 记录进展：选择已有任务、查看上次进展、输入本次结果，按需更新待办。
- 不同任务的进展草稿在当前页面内隔离；切换回原任务恢复其草稿。
- 支持 Tab 和 Cmd/Ctrl + Enter；真实桌面全局快捷键只作为视觉说明，不在浏览器注册。
- 新建与记录成功有明确结果状态；任务完成后可在“已结束”重新打开。

八个评审页面：插件主界面、展开记录、四象限、快捷新建、快捷进展、截止日历、设置、已结束。主界面中的新建弹窗、搜索空状态、管理分组、编辑任务也可操作。

## 配色参考与取舍

2026-09-29 查看：

- [Radix Colors：色阶用途](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)：背景、交互背景、边界和文字分别使用不同层级。借鉴其功能分层方法，不声称这些手工色值是官方 Radix 色板。
- [Realtime Colors](https://www.realtimecolors.com/)：把配色放入具体界面中比较，并检查前景／背景对比。
- [Happy Hues](https://www.happyhues.co/)：参考同一色板在背景、正文和动作中的实际分配。
- [Linear UI redesign](https://linear.app/now/how-we-redesigned-the-linear-ui)：参考减少界面噪声、统筹底色／强调色／对比度，以及不同容器下的层级一致性。不是复制 Linear 品牌。

taste 使用方式：这是保留风格的 redesign，主体属于工具 UI，只应用品牌保留、配色一致性、形状系统和有目的的动效。普通方向 variance 5 / motion 3 / density 7；工业 direction density 8；霓虹的多色与局部辉光来自用户明确要求。没有使用展示网页的大标题和营销动效规则。交互原型沿用项目已有原生 HTML/CSS/JS 与 Lucide，避免为了演示引入新框架。

## 验证与边界

浏览器中实际操作并确认：卡片展开、保存进展并更新历史、搜索与空状态恢复、新建任务并出现在看板、快捷进展键盘提交、任务选择与草稿隔离、待办计数、完成及重新打开任务、截止日历的日期切换、分组／四象限切换、设置里的深浅模式、窄窗口两面板切换。

实际截图保存在 `screenshots/`：六款主界面、六款快捷新建、六款快捷进展，以及六款另一种明暗模式；另有窄窗口和代表性深入页面。主界面用 1100×700 验证，快捷窗口用 1100×780，窄窗口用 375×812。控制台无页面错误。

对六款的十二种明暗状态测量了 token 对比度：正文最低 11.64:1；辅助文字对卡片／画布／次级背景最低 4.59:1；主按钮最低 5.59:1；优先级与截止日期文字最低 4.54:1。此为这些语义配色组合的核验，不等同完整无障碍认证。

原型不接真实 vault、网络服务、桌面系统快捷键或文件保存。图片入口展示已标注的示例附件，不执行真实上传。设置中的自动归档开关为视觉示意，未改变演示数据策略；紧凑显示仅作用于当前视图。页面刷新、切换评审主题或重新载入 iframe 会恢复示例数据。日期固定在 2026-09-29 的演示周，不伪装实时数据。
