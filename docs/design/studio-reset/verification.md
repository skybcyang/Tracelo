| 检查 | 结果 |
| --- | --- |

| 1280 × 720 工作台 | 两列分组，保留时间线 |
| 1024 × 768 工作台 | 两列任务，任务／时间线切换正常，无页面横向溢出 |
| 375 × 812 工作台 | 单列任务，无页面横向溢出 |

| 深浅色 | 均截图并目视检查；原生控件颜色随页面主题切换 |
| 四象限 | 桌面四区域同屏，各自滚动；完整内容可从详情访问 |
| 创建 | 输入名称、选择分组／优先级、填写待办及初始进展后成功创建 |
| 追加进展 | 新记录出现在完整历史最前，最新摘要更新 |
| 待办 | 勾选后计数更新，历史追加对应变更 |

| 搜索 | 能命中进展正文；进入任务后高亮并定位对应记录 |
| 搜索空状态 | 无匹配时显示关键词与下一步说明 |
| 快捷记录 | 关闭后再打开仍有会话草稿；提交后最新进展更新 |
| 设置 | 改为两列、关闭卡片摘要后，回到任务看板生效 |
| 日期与空状态 | 切到次日，显示对应截止任务及无记录提示 |
| 键盘 | Esc 关闭搜索正常 |
| 浏览器日志 | 验证时读取的最近 error 日志为空 |
