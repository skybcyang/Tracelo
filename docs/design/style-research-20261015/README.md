# Tracelo 整体风格调研

调研日期：2026-10-15。用户要求：调研适合本项目的好看卡片风格，整体插件可以更大胆，参考 GitHub 开源前端 UI 库。本轮交付调研和候选小样，未选定正式方向，未授权实施整个改版。

## 先看结果

[打开风格对比页](style-explorer.html)。三个候选使用相同的合成任务内容；保留双层顶栏、卡片横排、右侧日历和工作对话。点击「记录进展」可以原位展开输入区域，其他按钮及对话只是视觉占位，不保存、不调用模型。现状采用当天已有安装截图，视口不同，只用于认识整体气质，不用于尺寸比较，也不是本轮实机复验。

推荐先比较「触感工作卡」和「编辑式纸卡」。前者用实体卡片的色块和按键手感增加亲近感；后者把最新进展变成阅读主角，变化最大。是否改善推进意愿仍需真实使用反馈，不能由图片或库的热度证明。

## 当前界面的判断

来源：[此前卡片设计](../card-refresh.md)、当天安装留档、当前 `src/task-card.ts` 和 `package.json`。

这是用于恢复工作上下文的持续任务卡片产品，主要阅读对象是最新进展，主要动作是继续记录。当前截图中属性、进展和按钮都有相近灰色底块，层级容易趋同；多张卡一起出现时，重复的框比内容更抢眼。此前增加字号、柔化阴影改善了可读性，但整体语法变化较小。

候选保留横向卡片与右侧工作区；把边界、排版、材质与操作反馈拉开。没有加入假的完成百分比、每日积分、自动焦点推荐或任务自动排序。主题色是候选探索，尚未覆盖「素白」默认主题的既有决定。

## 三个候选

### 触感工作卡

场景：桌面上的实体索引卡。调性是安静中有活力、边缘精致、密度中等、操作有分量。浅绿色／杏色按分组区分，不按任务位置任意轮换，不再叠满灰色标签。卡头、正文、按钮靠细线与触感区分；中文无衬线保持容易扫读。

借鉴 Kokonut 的操作质感、coss 的分层控件，转换成整个工作台共同使用的语言。最值得保留的一刻是按下记录入口、卡片从原位置自然长出编辑区。目标动作可采用约 180–240ms 的短过渡，按压 1px，支持中断和减少动态效果；这只是待实现参数，小样没有验证完整展开动画。

推广到整体：创建弹窗采用同样的卡头与底部操作；设置以浅底分区；历史事件使用纸面分隔；快捷窗口复用实体按钮。风险是大面积分组色可能压过内容，需要在素白与深色下重新校准。图标小样采用系统 emoji，正式版本沿用项目离线 Noto。

### 编辑式纸卡

场景：随时可以接着写的工作札记。调性是精致、较密、安静但文字有力量。小标题定位任务，19px 宋体突出最新进展，时间移到进展之后；分组以出版物式横线和字级区分，卡片接近直角，按钮采用明确下划线。

coss 提供信息分层的参考，排版方向是针对中文任务记录的原创转译，并不是声称某个库自带该设计。最值得保留的一刻是打开后马上读到上次停下的那句话。整体变化最大，黑白也成立。

推广到整体：历史像连续日志、创建像短文稿、日历像编辑日程，控件仍用无衬线。风险是更大的进展字会减少两行可见字数；小样已有截断，真实实现需要自然展开读全文，不以更多省略换取表面整齐。跨平台宋体选择也需要明确。

### 轻悬浮面板

场景：一套轻盈的桌面面板。低对比冷灰画布、白色曲面卡片、内凹阅读区、深色胶囊动作；右侧工作区从贴边侧栏成为独立面板。使用细边缘和阴影表达层次，不依赖大面积实时模糊。

借鉴 SmoothUI 的组件质感与 coss 的界面一致性。推广到创建、设置、图片预览、快捷工具最顺畅。风险是容易落回常见圆角卡片审美，辨识度低于前两种；不能因为浮层增加而挤窄卡片和右侧正文。

## 实施适配判断

当前插件通过 Obsidian DOM API 创建界面，未使用 React／Tailwind。以上库大多面向 React，组件不能直接安装后替换现有卡片。建议先确定视觉语言，使用现有主题变量、CSS、DOM 与已有展开机制实现；只有某个独立组件确实显著节省工作时，再评估引入依赖。

整体改版的依赖顺序：主题变量与卡片状态 → 共享按钮／表单／菜单 → 日历与历史／对话 → macOS／Windows 快捷界面。后续实施前应补选中方向的分组／四象限、展开／展示、深色与短窗口小样。四象限区块仍是 2×2，内部卡片横排；不能把视觉探索变成行为重写。
