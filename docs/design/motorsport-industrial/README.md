# Motorsport / 工业版

完整可交互 mockup，默认金属灰浅色；支持深色切换。BMW M 配色关系、硬边网格、等宽数据和三色分组标识。

运行与验证记录见 [三款方案说明](../variants/README.md)，页面对比见 [对比入口](../variants/index.html)。

`index.html` 是交互入口，`variant.css` 是该方案的设计层，`01` 至 `14` PNG 是浏览器截图。`?screen=create|detail|quick|search|transfer|groups` 可直接打开弹窗；`?page=timeline|archive|settings` 打开页面；`?view=quadrant` 打开四象限；`?theme=dark` 打开深色。

示例数据仅保留在当前页面会话，刷新恢复，不接入正式插件。
