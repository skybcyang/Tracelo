# 命名、迁移与导入导出

状态：当前开发版已实现，未发布新版本。实现与验证记录见 [需求与验收基线](../requirements.md#12-当前实现)。

## 文件与目录

每个任务只生成一份正式 Markdown；待办、DDL、进展和历史都包含在其中。`agent.md` 和 `_groups.md` 是任务目录的共享文件；草稿与界面状态继续存入插件 `data.json`。保留备份与只读存档约定。

默认命名为 `2026-09-26 完成支付模块.md`，材料目录为 `工作记录/材料/2026-09-26 完成支付模块/`。日期使用原创建事件记录的本地日期，不重新按当前时区计算。重复名称（含大小写、Unicode 规范化后的重名）追加 `（2）`、`（3）`；序号在后续保存时稳定。文件系统不支持的字符替换为短横线，标题最多取 60 个 Unicode 字符，卡片标题完整保留。

任务内部 ID 不变，`archiveName` 保存文件名主体，`materialFolder` 保存已创建材料目录的相对路径。从插件改名会同步调整任务文件和材料目录，日期不变。未创建目录的任务不因此创建目录。换组、结束、重开均不改变名称。外部手工路径链接不自动更新。

旧 UUID 文件先生成迁移快照，再逐个迁移并校验。恢复日志记录原文件内容与目录位置，失败回退，中断后下一次加载恢复。没有待办、DDL 或材料的任务仍然保持这些字段可选。正式任务文件不支持手工修改／改名。

## 入口与流程

工具栏“导入与导出”、设置页同名按钮及命令面板打开同一个弹窗。沿用现有模态窗与按钮设计，不为每张卡片增加导入导出控件。

导出：点击“导出全部数据” → 显示生成进度文案并禁用重复操作 → 生成带日期时间的下载文件 → 显示卡片与材料文件数量。导出包含草稿，应将导出包视为完整私人工作数据。

导入：选择文件 → 校验 → 展示新增／跳过卡片、新增分组、材料文件数量 → 点击“确认导入” → 显示导入结果。选择、预览或关闭弹窗不会写入任务。损坏文件显示就近错误并禁用确认；可重新选文件。处理期间主视图暂不可操作，数据操作与任务写入排队执行。

## 包格式与冲突

`.tracelo.json` 使用 `format: "tracelo"`、`version: 1`，携带任务、分组、状态及材料条目。二进制材料使用 Base64 和 SHA-256，空目录也有独立条目。最大 100 MB（编码后的整个包），超过时明确报错，不生成残缺备份。更大的材料需另行复制。本版不支持导入任意 Markdown、旧版散装 JSON 或 ZIP。

- 已有任务 ID：整张跳过，包括该任务的材料和草稿。本地历史不被覆盖，不自动合并不同进度。
- 新 ID、同标题：另建任务，按日期与名称分配可用序号。
- 同名分组：复用本地分组身份；不同名称的 ID 冲突：新分配 ID。
- 空仓库恢复视图和手动排序；合并到已有仓库时保留本地排序并补入导入任务。
- 拒绝重复 ID、缺失分组、无效任务日期、目录穿越、大小写重名材料、父目录缺失及校验和不匹配。

## 故障与恢复

导入开始前备份本地任务、分组和状态。材料在插件备份目录下的独立临时目录写入、读回校验；之后才移入已分配的材料目录。事务记录在写入前落盘，包含待导入 ID、原分组／状态和目录移动记录。失败时回退；进程中断后，下次加载先恢复再展示任务。若恢复本身失败，保留恢复记录和备份并报错，不清空用户数据。

导出已关联但缺失的材料目录时停止并提示找回目录，避免默默生成缺材料的包。任务每日备份继续按最近 7 个备份日期轮换，不包含材料；材料完整备份使用导出包或仓库备份。

## 验证

真实临时文件系统覆盖命名、重名、改名、旧数据迁移、保存失败回退、写入中断恢复、材料字节完整性、空目录、导入冲突、重复导入、手动排序和导入中断恢复。浏览器加载实际插件代码验证下载、预览、取消、错误提示、确认导入、并发创建后导出，以及卡片空白点击、标题折叠、按钮隔离、右键菜单和响应式布局。
