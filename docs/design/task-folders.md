# 卡片操作与任务文件夹

## 第一版范围

每张卡片仍对应一个任务存档。默认不创建材料目录；用户选择“创建文件夹”时才创建 `工作记录/材料/<创建日期 任务名称>/` 并通过系统文件管理器打开。同日重名追加 `（2）` 等序号，沿用任务文件的名称。内部按稳定 ID 关联，并保存材料相对路径；任务改名时同步调整文件和已存在的材料目录，创建日期不变。换组、完成或重新打开不移动、不删除目录。任务存档目录设置变更也不影响材料根目录。

本版不做材料计数、附件列表、关联文件或拖入文件。用户直接在系统文件管理器中管理材料；插件的任务轮换备份不包含该目录，完整导出包会包含已有材料。导入导出和旧目录迁移见 [存储与迁移设计](storage-transfer.md)。

## UI

- 无目录：卡片不显示空占位，不增加高度。三点菜单首项为“创建文件夹”，使用 folder-plus 图标。
- 有目录：菜单首项为“打开文件夹”，使用 folder-open 图标；标题与三点菜单之间显示同样的文件夹快捷按钮。
- 快捷按钮沿用现有配色、焦点轮廓、24px 桌面点击区域；窄屏扩大到 44px。提示“打开任务文件夹”，无障碍名称包含任务名称。
- 右键与三点按钮调用同一份宿主原生菜单；保留改名、分组、象限、截止日期、完成等现有操作。

## UX

| 操作 | 结果 |
| --- | --- |
| 左键点击折叠卡片空白、正文、元信息 | 选中并展开，同时切换任务时间线 |
| 左键点击已展开卡片空白 | 保持展开，不丢失编辑上下文 |
| 点击标题／键盘 Enter 或 Space | 保留原有展开与收起切换 |
| 卡片右键／标题焦点下 Shift+F10 | 打开操作菜单，不展开卡片 |
| 输入框内右键 | 保留系统文字编辑菜单 |
| 勾选、按钮、输入、选中文字、拖动卡片 | 不额外触发展开或收起 |
| 创建文件夹 | 按需创建父目录，成功后直接打开，卡片出现图标 |
| 打开文件夹 | 打开现有目录，不重复创建，不追加任务进展，不改变排序 |

## 边界状态

- 重复操作：同一任务创建／打开进行中不重复执行；快捷按钮禁用并标记忙碌。
- 同名普通文件占位或创建失败：显示错误，不覆盖文件、不显示虚假成功图标；保留任务和材料。
- 系统文件管理器打开失败：明确提示目录仍保留，可重试打开。
- 外部移动／删除目录：根据实际目录状态更新图标和菜单；旧的“打开”操作不悄悄创建空目录，提示恢复原位置或通过菜单重新创建。
- 移动端或非本地文件系统：保留其他任务功能，文件夹操作禁用并注明“仅桌面端”。
- 材料目录不放进插件管理的 `任务/` 中，用户可以自由编辑其中内容。

## Windows 打开目录（0.5.0）

Windows 使用 `explorer.exe` 直接打开目录，路径作为单独参数传入，不经过命令解释器；其他平台仍使用 Electron `shell.openPath`。此分支用于规避 Electron 在 Windows 上将文件夹打开到后台的[已知问题](https://github.com/electron/electron/issues/36765)。不修改系统焦点策略、不使用置顶窗口或键盘模拟。

启动失败保留已创建目录并显示错误，用户可重试。Explorer 可能复用已有进程，因此以启动事件确认已发出请求，不以其退出码判断导航成功。自动测试覆盖 Windows 分支、中文／空格／特殊字符路径、启动错误和重试；当前开发环境为 macOS，真实 Windows 前台激活仍需人工验收。

## 区域新建入口（0.5.0）

每个分组（含未分组）和每个象限在任务之后放置一张虚线新建卡，空区域直接显示该入口，已结束区不放入口。卡片等宽，固定占一格 148px，与现有 12px 网格间距一致；不计入任务数量，不参与任务排序。

加号、标题“新建任务”和一行辅助说明居中；使用现有冷灰／深色变量，悬停及键盘焦点增强边框，按下不改变尺寸。整个卡片是原生按钮，支持 Enter／Space；空区域同时提示可以拖入已有任务，拖放不会打开新建弹窗。

点击分组入口预选该分组，象限仍由用户选择；点击象限入口预选该象限，分组默认未分组。用户可修改预选项，待办和日期仍为可选。取消不创建数据，焦点返回入口；创建成功清除当前搜索，选中并展开新任务。顶部新建按钮继续保留。
