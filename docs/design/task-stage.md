# 玻璃悬浮工作台：结构与可点击原型

2026-10-15。用户已选定玻璃悬浮方向并明确主体结构，随后授权制作 Mockup；已完成可点击原型。用户追加要求加强透明毛玻璃和周边流光，先做大画幅、不处理手机形态；已据此完成桌面材质迭代；10月16日接续原对话，将光效收敛为银灰周边柔光，强化封面标题并恢复左进展／右待办与详情布局。10月16日用户进一步授权按Mockup生产实施，新增条件目录树列与无尽循环，最新确认见文末。前文中的“尚未确认／仅原型”段落保留为当时设计记录，已由文末实施确认覆盖。

## 用户明确的结构

- 主页面上方是饭盒式布局的展示台，高度不要求严格占一半，组织任务的待办、详情和进展。
- 上方展示当前选中任务的内容，点击下方卡片切换。
- 采用玻璃悬浮工作台，强化卡片视觉；背景周边可有光效或动效。
- 下方卡片不再显示进展，改为横长条中的封面流式陈列，鼠标滚轮在该区域可滚动浏览。
- 分组与四象限都作为筛选条件，支持同时生效，即分组条件与象限条件取交集。
- 点击全屏按钮后，才采用类似当前插件的铺开卡片布局。
- 右侧栏如何设计尚未确定，用户要求建议。

以上为本轮新方向，覆盖旧小样中默认卡片网格与卡片进展摘要的设想；不等同于已修改生产行为。

## 右侧栏建议（尚未确认）

优先建议可收起的工作助手面板：上方保留现有日期切换、整周日期、日历入口与所选日截止列表；下方默认工作对话，并可显式切换到活动记录或任务完整历史。展示台已经承载任务内容，右侧不再重复详情与待办。

可比较三个形式：常驻工作助手、按需展开的窄侧边轨、以活动回顾为默认的侧栏。推荐第一种为宽窗口默认，第二种为用户收起或窄窗口状态。它们是建议，尚未写入正式需求。

选中任务与对话引用保持独立：提供明确的“引用当前任务”操作；翻卡不静默改变正在编辑或已发送消息的引用。AI 写入仍先出可编辑提议，再由用户确认。

## 视觉与交互建议（尚未确认）

- 周边使用宽而柔和的环境光、缓慢位移或呼吸；正文背后保持稳定。玻璃外壳较通透，文字阅读面增加实色遮罩，支持静态／减少动态效果。
- 封面卡以任务标题、分组、象限和可选截止构成身份；不强制用户配置封面，不重复放进展。中心卡较正、两侧轻透视，保持相邻标题可读。
- 滚轮建议只移动浏览位置，点击／键盘确认才切换展示台；同时保留左右按钮与位置计数，不自动轮播。此滚动与选择的区分待确认。
- 筛选后当前任务不在结果内时，建议保留展示台和草稿，并明确提示；不静默切走正在编辑的任务。
- 全屏建议先按插件工作区展开；退出恢复选中任务、筛选与横条位置。全屏是否保留筛选、如何显示全部任务、卡片是否继续不显示进展仍待明确。

## 待选择与待验证

视觉方向已选定玻璃悬浮，不再沿用此前轻触感／编辑式二选一建议。展示台应突出最新进展，并给长详情、图片和待办留出阅读空间，同时保持下方任务可见。

新结构涉及点击卡片的语义；原位记录进展是否迁移至展示台、原展示模式如何衔接仍待设计确认，不因本次结构讨论直接删除既有行为。切换任务不能丢草稿，也不能隐式改变侧边栏对话的引用对象。

可点击实现见 [玻璃工作台 Mockup](glass-workbench/README.md)，实际截图与交互检查见 [原型验证](glass-workbench/validation.md)。使用隔离合成数据，编辑仅在内存，刷新还原；未修改生产代码、任务数据或安装。此前风格小样见 [整体风格调研](style-research-20261015/README.md)，它们不代表本次新结构。

当前原型将上面的交互建议做成可试用行为：滚动只浏览、点击切卡，工作区全屏保留筛选，日历＋工作对话作为候选侧栏。可试用不等于用户已验收这些取值。技术检查结论为现有 TypeScript／原生 DOM 可以实现，正式接入需拆分筛选与布局状态、保持编辑节点稳定、控制模糊和动效合成成本，详见原型说明的架构表。

参考：[Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)、[W3C 轮播交互指南](https://www.w3.org/WAI/tutorials/carousels/)。参考用于讨论材质层级、键盘操作与动画控制，不作为原型或生产验证证据。

用户反馈轮换带来的重复卡片观感不好，明确取消轮转。本决定覆盖上文“无尽循环”的旧要求：下方任务牌组每个任务仅一张封面，左右按钮、方向键和滚轮浏览到首尾停止，不再从另一端接续。浏览与选择继续分离，点击／回车才切换展示台，草稿与对话引用保持原规则。自由排布原型同步取消首尾回绕；自由排布本身仍仅为设计原型。实现和本地安装证据见[取消循环验收](../validation/2026-10-16-bounded-covers.md)。
